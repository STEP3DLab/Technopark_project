# BREACH / ARCADE

Две самостоятельные мини-игры в дополнение к [BREACH 3](../). Оригинальная игра не изменялась.

- [PULSE](pulse.html) — 60-секундная охота за захватчиками. Одно касание — один выстрел. Есть серия попаданий, бронированные цели и золотые противники, вызывающие цепной взрыв.
- [RIFT](rift.html) — 70-секундная защита центрального ядра. Управление свайпами. Одним жестом можно уничтожить несколько захватчиков и получить бонус за мульти-срез.
- [Выбор игры](index.html) — отдельная страница двух режимов.

## Запуск

Откройте страницу по HTTPS на телефоне. Выберите «АКТИВИРОВАТЬ КАМЕРУ», разрешите доступ к основной камере смартфона или воспользуйтесь кнопкой «ИГРАТЬ БЕЗ КАМЕРЫ». Игра работает и с мышью на компьютере.

Для PULSE касайтесь захватчиков. Для RIFT проводите пальцем через захватчиков до того, как они достигнут ядра. Звук и камера выключаются отдельными кнопками. Паузу можно включить вручную; при переключении вкладки игра ставится на паузу автоматически.

Рекорд сохраняется локально в браузере отдельно для каждого режима. Регистрация, аккаунт и отправка видеопотока не требуются.

## Важное ограничение

Здесь применяется **AR-наложение на изображение с камеры** — игровой слой рисуется поверх живого видео. Это не полноценное пространственное WebXR-отслеживание: положение захватчиков не фиксируется относительно реальных стен, они не скрываются за физическими углами и геометрия комнаты не сканируется. Для игры с реальным закреплением объектов в комнате требуется отдельный WebXR/SLAM-режим и поддерживаемые устройства.

## Технические детали

Чистые HTML + CSS + Canvas 2D + Web Audio API, без сетевых зависимостей и внешних библиотек. Поддерживаются Pointer Events, устройства с различной плотностью пикселей, вертикальный экран, клавиатурная пауза (Escape), вибрация при наличии поддержки. Игры можно открыть как локальный статический HTML (без камеры), а камере требуется HTTPS или localhost.

## Проверки

- Успешная синтаксическая проверка JavaScript.

Реальный физический тест видеокамеры, тактильной чувствительности и производительности на конкретном смартфоне отдельно не проводился.
