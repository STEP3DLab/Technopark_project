# МОБОТ — работа на архивной фотографии

Готовая демонстрация проекта «Живая инженерная память» для обсуждения с А. Ф. Батановым.

- [Открыть демонстрацию](https://step3dlab.github.io/Technopark_project/mobot/)
- [MP4 для показа, 52 секунды](https://step3dlab.github.io/Technopark_project/mobot/assets/mobot-presentation.mp4)
- [MP4 с пояснениями, 52 секунды](https://step3dlab.github.io/Technopark_project/mobot/assets/mobot-route.mp4)
- [Листы для записей](assets/Mobot_review_frames.pdf)
- [Сверка с архивными референсами](assets/Mobot_reference_audit_2026-11-03.pdf)

Фотография и архивные цифры сохранены. Масштаб, маршрут, крепление датчика и темп показаны условно и требуют технической сверки. Архивные отметки не являются результатом демонстрируемых замеров.

Страница включает сравнение с исходным снимком, два цикла, покадровое перемещение, режим показа, замечания и перенос заметок через JSON. Заметки остаются в браузере посетителя и не отправляются в репозиторий. Для переноса с прежней страницы нужно скачать там резервную копию JSON и загрузить её здесь.
