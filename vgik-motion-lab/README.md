# КАДР — виртуальная студия РГСУ × ВГИК

Демонстрационный 3D-прототип роботизированной съёмочной установки Технопарка РГСУ. Студия позволяет поставить сцену, запрограммировать движение руки с камерой ключевыми позами и получить последовательность изображений для покадровой анимации.

**[Открыть студию](https://step3dlab.github.io/Technopark_project/vgik-motion-lab/)** · версия 1.1.0

## Возможности

- Рука с шестью регулируемыми осями, шарнирами, крепежом и камерой; общий обзор площадки и отдельный монитор камеры 16:9.
- Три объекта съёмки: маленький робот, макет ракеты и абстрактная композиция. Поза или поворот объекта записываются вместе с движением камеры.
- Готовые движения для демонстрации: облёт, плавный наезд и подъём камеры.
- Изменение углов суставов, наклона и крена камеры, фокусного расстояния; ручное управление запястьем либо слежение за объектом.
- Запись, удаление и точное перемещение ключей по времени. Плавная, линейная интерполяция и режим «Удержание до ключа».
- Предыдущий и следующий кадр, шкала времени, траектория, сетка площадки, поле зрения, композиционная сетка и три схемы освещения.
- Съёмка отдельных PNG или всей программы, просмотр дубля, восстановление предыдущего дубля и экспорт ZIP.
- Автосохранение проекта и черновика позы; отмена и повтор действий; импорт/экспорт JSON и читаемая программа виртуального стенда.

## Демонстрация за две минуты

1. Откройте студию и нажмите **«Запустить демо»**. Выберите готовое движение камеры; справа виден получаемый кадр.
2. Переключитесь на **«Через камеру»**, чтобы показать съёмочный ракурс крупно. Вернитесь в **«3D-студию»**, чтобы показать манипулятор и траекторию.
3. Остановите движение, выберите время на шкале и измените положение робота, объектив или позу персонажа. Нажмите **«Записать ключ»** либо **«Записать ключевую позу»**. При переходе к другому времени допустимая изменённая поза записывается автоматически.
4. Для точной настройки выберите ромб ключа, задайте **«Время ключа»** и нажмите **«Сдвинуть»**. Если в этой точке уже есть другой ключ, студия предложит выбрать другое время.
5. Откройте **«Снятые кадры» → «Снять всю программу»**. Для 8 секунд и 12 кадр/с получится **ровно 96 кадров**. Просмотрите результат и скачайте кадры одним ZIP-архивом.
6. Сохраните JSON через **«Проект» → «Сохранить проект»**, чтобы перенести постановку на другой компьютер.

## Управление

| Действие | Управление |
| --- | --- |
| Вращение общего вида | Перетаскивание мышью или одним пальцем |
| Масштаб | Колесо мыши или жест двумя пальцами |
| Пуск / пауза | Кнопка воспроизведения или пробел |
| Запись ключевой позы | «Записать ключ» или `K` |
| Снимок текущего кадра | «Снять кадр» или `C` |
| Предыдущий / следующий кадр | Кнопки возле воспроизведения либо стрелки влево / вправо |
| Выбор ключа | Ромб на шкале |
| Перемещение ключа | Поле «Время ключа» → «Сдвинуть» |
| Отмена / повтор | «Отменить» / «Повторить», `Ctrl/Cmd+Z` / `Ctrl/Cmd+Shift+Z` |
| Отказ от незаписанной правки | «Отменить правку» под кнопкой записи |

Горячие клавиши студии не перехватывают работу с полями ввода, кнопками, ссылками и открытыми диалогами. На небольшом экране панели перестраиваются, а действие записи ключа остаётся доступным.

## Черновик и история действий

В браузере сохраняются проект, текущее время и незавершённая правка позы. Численный ввод сохраняется сразу при изменении значения, ещё до выхода из поля. После перезагрузки можно продолжить редактирование черновика. Переход по шкале сначала записывает изменённую позу; если запись невозможна, например из-за недопустимого положения или достижения лимита ключей, переход не уничтожает правку.

Отмена и повтор сохраняют до **30 шагов** текущей сессии. Восстанавливаются поза, время, выбранный ключ и состояние редактирования. История отмены не переносится через перезагрузку; сам проект и черновик сохраняются. При недоступном хранилище браузера интерфейс предлагает сохранить JSON.

## Кадры и длительность

Полный дубль содержит `N = ceil(длительность × частота)` кадров, снятых в моменты `0/fps … (N−1)/fps`. Погрешности вычисления около целых границ кадров учитываются отдельно, чтобы не возникал случайный лишний кадр.

Для **8 с × 12 кадр/с** это **96 кадров**, моменты от 0 до примерно 7,917 с и клип длительностью ровно 8 с. Конечный ключ на отметке 8 с остаётся доступен для просмотра и редактирования, но дополнительное конечное изображение не добавляется.

Если заданная длительность соответствует дробному числу кадров, клип округляется вверх до полного кадра. Например, **1,01 с × 12 кадр/с → 13 кадров → примерно 1,083 с**. Интерфейс и экспорт показывают длительность клипа отдельно от заданной временной шкалы.

Изображения снимаются в **1280 × 720** без интерфейса и вспомогательной сетки. За один проход доступно до **360 кадров**. При превышении лимита уменьшите длительность или частоту.

ZIP содержит:

- `frames/` — PNG в порядке воспроизведения;
- `project.json` — проект начала дубля;
- `captures.json` — частоту, режим дубля, фактическую позу и настройки каждого изображения;
- `frames.csv` — время каждого кадра;
- `README.txt` — пояснение к конкретной последовательности.

Снятый дубль сохраняет собственную частоту кадров и параметры, поэтому последующие изменения проекта не меняют его воспроизведение или экспорт. Для ручного дубля фактические позы каждого снимка записаны в `captures.json`.

После новой съёмки или очистки галереи доступна команда **«Вернуть прошлый дубль»**. Прерванная съёмка не заменяет предыдущий результат. Текущий и предыдущий дубль находятся в памяти страницы: скачайте нужные кадры до перезагрузки или закрытия вкладки. Видео MP4 не кодируется; последовательность PNG можно собрать в видеоредакторе.

## Проверка рабочей зоны

Когда 3D-сцена доступна, студия проверяет текущее положение и набор промежуточных поз программы. Проверяются конечность координат, пересечение корпуса камеры и звеньев с рабочей плоскостью, приближение камеры к области объекта и направление кадра. Недопустимая поза блокирует запись или съёмку с пояснением; предупреждение о выходе объекта из кадра помогает поправить композицию.

Эта проверка использует ограничивающие объёмы и дискретные положения. Она **не является полной проверкой всех столкновений**, гарантией свободной траектории между отсчётами или расчётом безопасности реального робота.

## Если 3D-просмотр недоступен

При отсутствии WebGL 2 или потере графического контекста интерфейс показывает состояние ошибки и кнопку **«Запустить снова»**. Редактор ключей, сохранение проекта и экспорт JSON продолжают работать. Просмотр движения и съёмка доступны после восстановления графики. Без 3D-сцены геометрическая проверка рабочей зоны не выполняется.

Ошибка загрузки файлов приложения обрабатывается отдельно: вместо бесконечного индикатора загрузки появляется сообщение и действие повторной загрузки.

## Границы прототипа

Это виртуальный учебный стенд. Геометрия и диапазоны суставов служат демонстрации принципа. Модель не является конструкторской документацией для изготовления, а экспортируемая программа не управляет реальными приводами. При включённом слежении J4–J6 задают смещение относительно направления на объект; при выключенном — локальное положение запястья относительно звеньев руки.

Расчёт нагрузок и динамики, проверка всех столкновений, калибровка и подключение физического контроллера относятся к дальнейшему инженерному этапу.

## Файлы и запуск

Статическое приложение HTML/CSS/JavaScript без сборки и серверной части. Three.js **r180** и `OrbitControls` находятся в `vendor/`; для запуска не требуется CDN. Геометрия сцены и текстуры создаются программно.

| Файл | Назначение |
| --- | --- |
| `index.html`, `styles.css` | Интерфейс, доступность и адаптивная вёрстка |
| `startup.js` | Загрузка приложения и обработка ошибки импорта |
| `main.js` | Интерфейс, состояние запуска, управление программой и дублями |
| `editor.js` | Черновики, отмена/повтор и сериализация сессии |
| `scene.js` | 3D-сцена, кинематические преобразования, проверка поз и съёмка |
| `motion.js` | Интерполяция, расписание кадров, проверка JSON и текстовая программа |
| `zip.js` | Подготовка ZIP-архива |
| `motion.test.mjs`, `editor.test.mjs`, `scene.test.mjs`, `zip.test.mjs` | Автоматические проверки |
| `AUDIT.md` | Результаты виртуального брифинга трёх экспертов и пределы проверки |
| `vendor/`, `assets/` | Локальные зависимости, лицензия и брендовые изображения |

Локальный запуск из этой папки:

```sh
python -m http.server 8000
```

Затем открыть `http://localhost:8000/`. Прямая загрузка через `file://` не подходит для модулей JavaScript. Для 3D нужен WebGL 2.

Проверки:

```sh
npm test
```

Набор содержит 44 проверочных сценария в четырёх файлах; геометрическая проверка охватывает 873 сочетания траекторий, объектов и поз. Подробности и ограничения описаны в `AUDIT.md`.

Папка публикуется в составе `STEP3DLab/Technopark_project` через GitHub Pages. Адрес проекта сохранён.

## Бренд и исходная концепция

Логотип РГСУ перенесён без изменений из ранее опубликованных материалов этого репозитория: `industrial-design-lab/assets/brand/rgsu-blue.svg` и `rgsu-white.svg`. Основные цвета: синий, тёмно-синий, белый и акцентный малиновый.

Концепция опирается на слайд «Механизмы для ВГИК»: камера для покадровой анимации, 3D-печатные звенья и корпуса, металлические оси и крепёж. Three.js распространяется по лицензии MIT; текст находится в `vendor/THREE-LICENSE.txt`.
