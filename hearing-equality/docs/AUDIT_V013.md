# Равенство по слуху — аудит и доработка 0.13

Дата: 29 октября 2026 года. Основа: опубликованный коммит 3c4731e89646f42a112202341483e29e8931369e; последняя версия этого приложения в нём — 0.12.

## Метод

Это аналитический аудит с пяти профессиональных позиций, выполненный ИИ. Внешние специалисты не привлекались; заключение переводчика или носителя РЖЯ не получено. Не следует представлять этот документ как независимую лингвистическую экспертизу. Замечания проверены по исходному коду, автоматическим тестам и интерфейсу в Chromium.

Главный продуктовый вывод: приложение должно помогать завершать задачу общения, а не только демонстрировать аватара. Новое позиционирование: **помощник для составления и передачи сообщений с экспериментальным вводом отдельных слов РЖЯ**. Это не универсальный переводчик РЖЯ.

## 1. Продукт и пользовательские сценарии

**Рецензия.** Начальный экран показывал аватара; полезный результат распознавания оставался в отдельном редакторе камеры. Не было завершённого пути в мессенджер. Сценарий привязан к посетителю и сотруднику, хотя инструмент может использовать любая пара собеседников.

**Доработано.** Экран «Общение» становится стартовым при входе без якоря. Старые ссылки #text, #camera и #video сохранены. Главная последовательность: составить → проверить → показать/скопировать/поделиться. Есть общий черновик до 2000 знаков, 24 текстовые фразы в четырёх группах с поиском, отдельный ответ собеседника, общая история с ролями «Вы» и «Собеседник». Старый второй редактор камеры скрыт; вместо него показан текущий общий черновик. Добавление в историю не выдаётся за внешнюю отправку.

**Проверка.** Вставка и отмена, поиск по всем группам, отсутствие обрезки длинного текста, копирование обеих сторон диалога. Повторное нажатие не дублирует ту же редакцию сообщения.

## 2. Доступность и интерфейс

**Рецензия.** Нужен сценарий без звука и без камеры, крупный текст для собеседника, понятный возврат из модального окна. На телефоне подробные инструкции и длинный список фраз отодвигали ответ вниз.

**Доработано.** Крупный показ через нативный dialog, закрытие Escape, возврат фокуса к инициатору; режимы увеличенного текста и контраста. На узких экранах фразы изначально свёрнуты, ответ собеседника расположен перед техническим объяснением, добавлен переход к ответу. Ошибки и состояния выражены текстом, а не только цветом/звуком. При отказе копирования доступно выделяемое поле ручного копирования.

**Вторая итерация.** Браузерный тест обнаружил потерю фокуса после отказа Clipboard API: отключённая кнопка теряла фокус до открытия диалога. Теперь инициатор запоминается до асинхронной операции и восстанавливается после закрытия окна.

**Граница проверки.** Горизонтальное переполнение отсутствует при ширинах 320, 360, 390, 768 и 1440 CSS-пикселей. Проверка реальными пользователями, TalkBack/VoiceOver и формальный аудит соответствия стандартам доступности ещё не выполнены.

## 3. РЖЯ и корректность распознавания

**Рецензия.** Пользователь должен видеть отличие готового примера, предположения алгоритма и проверенного им текста. Шесть слов нельзя представлять как перевод свободной речи. Нельзя молча отбрасывать отрицания или собирать произвольные предложения из известных жестов.

**Доработано.** Камера переименована в «РЖЯ → текст · эксперимент». Ограничение шестью отдельными словами видно до запуска. Добавление доступно только после подтверждения. В черновик поступает именно подтверждённое слово, а не последующая неподтверждённая правка поля. Слова из известных записей помечаются как демо; пометка сохраняется после редактирования и в истории/её экспорте. Быстрые фразы обозначены как текст, не как распознанные жесты. Аватар доступен для точного совпадения целого сообщения со словарём; неподдерживаемый текст не упрощается до знакомых слов.

**Не изменено.** Алгоритм DTW, шаблоны, пороги, независимая выборка и движения аватара. Улучшение качества распознавания не заявляется. Контрольные суммы исходных роликов и происхождение 266 кадров шести записей проверены штатным скриптом.

## 4. Приватность и контроль передачи

**Рецензия.** Автосохранение без явного выбора на общем устройстве опасно. Нельзя показывать «Отправлено», когда лишь открыто системное меню. Отмена отправки не должна уничтожать текст.

**Доработано.** По умолчанию черновик и история находятся только в памяти страницы. Сохранение только черновика в localStorage — отдельный выключенный переключатель с предупреждением об общем устройстве. История, видео и ответ собеседника не записываются этим механизмом. Ошибка чтения/записи хранилища видна; текущий текст не удаляется. Отключение сохранения удаляет запись при доступном хранилище. Новый разговор очищает черновик, ответ, историю экрана и стек отмены с подтверждением. Буфер обмена и скачанные копии не объявляются очищенными.

**Передача.** Share получает снимок текста на момент нажатия, без URL с сообщением. Успех системного API не объявляется доставкой адресату. При отмене или ошибке черновик остаётся. Не поддерживающий Share браузер получает ручное копирование. Голосовой ввод включается только по нажатию; предупреждение об обработке службой браузера показано заранее.

**Граница.** localStorage не зашифрован. Результаты испытаний старого исследовательского раздела очищаются отдельно; это указано при начале нового разговора. Код не может отозвать уже переданный текст или удалить сторонние копии.

## 5. Надёжность и сопровождение

**Рецензия.** Асинхронные результаты не должны заменять новый текст; новый интерфейс должен входить в офлайн-комплект, а прошлый подготовленный комплект должен переживать сбой обновления.

**Доработано.** Модель черновика выделена в communication-model.js. Добавлены ограниченный стек отмены, снимок передачи, явный лимит без молчаливой обрезки, обработка отказов хранилища/копирования/Share. Поздняя диктовка игнорируется после ручной правки, смены режима, скрытия вкладки или нового разговора; есть ограничение времени записи. Офлайн-комплект 0.13 включает три новых файла и содержит 39 ресурсов. Неизменённые модули ядра с URL версии 0.12 разрешены как явный совместимый вариант; остальные старые версии по-прежнему отклоняются. Подготовка остаётся атомарной.

**Сохранено.** Исходные модули platform.js, vision.js, recognizer.js, canvas-avatar.js и геометрия/сглаживание не переписаны. Поведение камер и аватара защищено прежними регрессионными тестами.

## Сценарий показа

Открыть «Общение» → набрать фразу → показать крупно → скопировать → добавить свою реплику и ответ собеседника в диалог. Затем отдельно: «Видео → текст» → известный пример → разбор готовых координат → подтвердить → добавить в сообщение. Прямо указать, что второй фрагмент — демонстрация известного образца. В конце открыть словарь аватара и сравнение с исходным видео.

Встроенная памятка и первые два слайда НТС приведены к этому сценарию.

## Следующий этап, который интерфейс не заменяет

Пилот с переводчиком и носителями РЖЯ, новые участники и записи, оценка понятности аватара, доли ошибочных принятых результатов, отказов и времени выполнения задачи. Предпочтительная цель — один сценарий и 20 целых сообщений, а не заявленное покрытие всего РЖЯ.
