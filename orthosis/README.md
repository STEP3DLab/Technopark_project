# ORTHOSIS V01 — коленный ортез
Публичный сайт: https://step3dlab.github.io/Technopark_project/orthosis/
Ревизия: 04.11.2026, компоновка для ненагруженных стендовых работ.
17 печатных деталей STL в миллиметрах, 23 STEP-модели печатных и покупных компонентов, общая STEP-сборка, а также исходный Python CadQuery и параметры JSON.
Угол сгибания в браузере демонстрирует только поворот рамы вокруг шарнира X; защита троса при сгибании скрывается, так как её кинематика не разработана.
Прежде чем печатать силовые рамы, изготовить калибр A17 и проверить посадки под 608.
Запрещено использовать V01 на человеке под нагрузкой или с активным приводом. Не подтверждены безопасность, посадка, силовая передача и циклическая надежность.
Бинарные файлы генерируются через GitHub Actions из оригинальной исходной CAD-модели, сохранённой с SHA-256 в source_bundle.b64.
