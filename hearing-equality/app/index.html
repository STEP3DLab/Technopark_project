Граница этой версии

Это технический демонстратор ограниченного словаря. Свободный перевод предложений и подтверждённое понимание РЖЯ в эту версию не входят.

Аватар Canvas 2D использует измеренные координаты. При потере кисти детектором её пальцы временно не показываются. Для реальных оповещений нужны проверенные переводы.

Источник движений — Slovo

Alexander Kapitanov, Karina Kvanchiani, Alexander Nagaev, Elizaveta Petrova. Slovo: Russian Sign Language Dataset.

Шесть исходных видеоклипов сохранены без изменения. Координаты автоматически извлечены с помощью MediaPipe; изображение аватара и переходы построены программно. Данные и их адаптация предоставляются по специальной публичной лицензии Slovo, как есть, без гарантии качества перевода. Авторы Slovo не заявлены проверяющими этого проекта.
