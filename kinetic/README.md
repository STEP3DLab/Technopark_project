# KINETIC — Анатомия движения

Интерактивный 3D-атлас протеза ноги, созданный для Технопарка РГСУ.

- Перетаскивайте модель мышью для вращения.
- Прокручивайте колёсико или двигайте нижний ползунок для раскрытия накладок и разнесения узлов.
- Нажимайте на накладки и точки, чтобы исследовать конструкцию.
- Shift + колесо, кнопки + / − или жест двумя пальцами изменяют масштаб.
- Режим «В движении» демонстрирует сгибание коленного узла.
- Пробел запускает и останавливает демонстрацию, R возвращает исходный вид.

Есть три варианта покрытия, прозрачные накладки и выбор ракурса.

## Запуск

Сайт статический, сборка и установка зависимостей не нужны. Все библиотеки включены в `assets/vendor/`.

Для локального просмотра запустите HTTP-сервер из этой папки, например `python -m http.server 8000`, и откройте `http://localhost:8000/`.

Для интерактивной сцены нужен браузер с WebGL 2 и аппаратным ускорением.

## О модели

Это авторский демонстрационный концепт. Геометрия и движение упрощены; модель не воспроизводит конкретное медицинское изделие и его расчётные параметры. Исследовательские источники доступны в интерфейсе, в разделе «О модели и источниках».
