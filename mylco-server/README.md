# Приём фотографий на mylco.ru

Разместите `mylco-photo.php` в корневом каталоге HTTPS-сайта mylco.ru. Обработчик рассчитан на PHP 7.4 или новее с PDO SQLite, GD/JPEG и работающей исходящей почтой для адреса `order@mylco.ru`. Для POST нужны лимиты PHP `upload_max_filesize` от 2 МБ и `post_max_size` от 3 МБ.

PHP создаёт каталог `mylco-photo-private` рядом с корнем сайта и сохраняет в нём закрытую базу SQLite. При нескольких сайтах в одном аккаунте задайте переменную `MYLCO_PHOTO_DIR` с путём в частный каталог вне всех публичных корней. Выделите доступ только процессу магазина. Обработчик удаляет записи старше 30 дней при следующем обращении. Срок хранения почты и резервных копий задаётся владельцем отдельно.

Проверьте GET на `https://mylco.ru/mylco-photo.php`. После ответа с `service=mylco-photo-v1` и `ready=true` страница «Оценить по фото» при следующем открытии предложит отправку с сайта. Согласуйте тест с мастерской, отправьте собственное тестовое изображение и сверьте номер заявки с письмом в рабочем ящике. Заявки на CAD идут на `order@mylco.ru`, заявки на печать — на `mylco@inbox.ru`.

Подтверждение означает, что заявка сохранена в базе магазина и почтовый транспорт принял уведомление. Записи с `notified=0` сохраняются для разбора владельцем через закрытый доступ к базе. При временной ошибке покупатель может повторить запрос с тем же идентификатором. На витрине доступна подготовка письма с фотографией, пока серверный приём выключен.
