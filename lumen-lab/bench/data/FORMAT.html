CSV для двухканальной записи мощности

Одна строка содержит общую временную метку и до двух показаний мощности из уже полученной записи. power-template.csv содержит заголовок для заполнения. power-example.csv содержит синтетические числа для проверки расчёта.

Столбец Единица Содержимое
time_s с Обязательная неотрицательная временная метка. Каждая следующая метка строго больше предыдущей.
ch1_W Вт Неотрицательное показание первого канала или пустое поле.
ch2_W Вт Неотрицательное показание второго канала или пустое поле.

Сохраните CSV в UTF-8. Допускаются начальная метка BOM и переводы строк LF, CRLF или CR. Соблюдайте имена, регистр и порядок столбцов. Пустые строки пропускаются. Каждая запись занимает одну строку и содержит все три поля. Если показание отсутствует, оставьте поле пустым, сохранив разделитель. Число 0 означает зарегистрированный нуль. Две пустые мощности сохраняют в наборе только метку времени и прерывают покрытие обоих каналов.

При разделении полей запятой используйте десятичную точку. Можно заключить поля в двойные кавычки.

time_s,ch1_W,ch2_W
0,0.25,0.10
0.5,,0.12

При разделении полей точкой с запятой допускаются десятичная запятая и точка. Пробелы и табуляция по краям полей пропускаются. Допустима экспоненциальная запись, например 2.5e-3. Разряды числа записываются слитно.

"time_s";"ch1_W";"ch2_W"
"0";"0,25";"0,10"
"0,5";"";"0,12"

Перед заголовком синтетического набора поместите отдельную строку # SYNTHETIC. Сохраните её при повторном экспорте примера. Если метка отсутствует, происхождение данных требует отдельного подтверждения. Шаблон с одним заголовком открывается как пустая запись.

Расчёт

Для каждого канала n — число заполненных показаний. Минимум и максимум берутся по всем таким показаниям, в том числе одиночным. Покрытие — сумма длительностей интервалов, на которых у данного канала заполнены обе границы в соседних строках, а шаг между ними не превышает заданный предел. Пустое поле разрывает оба прилегающих интервала соответствующего канала. При длинной паузе исключается весь интервал. Равенство шагу-пределу допускается.

На принятом интервале интеграл мощности равен (P₁ + P₂) × (t₂ − t₁) / 2. Сумма выражена в джоулях, поскольку 1 Вт × 1 с = 1 Дж. Это оценка по показаниям измерительного канала с линейной интерполяцией между отсчётами. При нулевом числе принятых интервалов интеграл отсутствует (null), а покрытие равно 0 с. Полностью заполненный интервал с двумя нулевыми показаниями даёт 0 Дж.

Общее покрытие учитывает интервалы, принятые в обоих каналах. Оно описывает доступность данных на общей шкале времени. Для определения времени одновременного физического излучения и энергии в объекте нужны отдельные данные. Полная длительность записи — разность последней и первой меток, включая пропуски.

Чтобы получить предлагаемый предел, модуль сортирует длительности соседних шагов и умножает их медиану на три. При чётном числе шагов берётся меньшее из двух центральных значений. Для пустой или одиночной записи предлагается 1 с. Запишите фактически выбранный предел вместе с результатом.

Контрольный результат для power-example.csv

В примере 20 строк от 0 до 12 с. Обычный шаг равен 0,5 с. При пределе 1,5 с интервал от 6 до 9 с целиком исключается. На отметке 3,5 с отсутствует показание первого канала, на отметке 5 с — второго.

Величина Канал 1 Канал 2
Заполненных показаний 19 19
Минимум, Вт 0,09 0,05
Максимум, Вт 0,81 0,74
Принятых интервалов 16 16
Покрытие, с 8 8
Интеграл мощности, Дж 3,765 2,985

В обоих каналах приняты 14 общих интервалов суммарной длительностью 7 с.

Пределы импорта

Модуль обрабатывает до 100 000 записей, 8 388 608 кодовых единиц UTF-16 после декодирования, 200 002 физических строк и 1024 кодовых единиц на строку. Численные пределы формата составляют от 0 до 10¹² с для времени и от 0 до 10⁹ Вт для мощности. Наименьшее поддерживаемое положительное значение времени или мощности равно 10⁻¹⁰⁰. Параметры диапазонов прибора указываются в его документации.

При импорте числа преобразуются в JavaScript Number. Если две метки округлились к одному представимому числу, импорт сообщит о повторе. Длительности вычисляются из десятичной записи нормализованных меток. Интегралы суммируются с компенсацией ошибок округления. При ошибке файл отклоняется целиком, а сообщение о некорректной записи указывает её физическую строку.

Одновременное превышение двух порогов

В разделе качества данных можно ввести пороги различимости P1 и P2 из документов на два внешних измерителя. В отдельный показатель входят только смежные строки в пределах принятого шага, в которых оба канала строго выше своих порогов на обоих концах интервала. Пропуск, слишком длинная пауза или равенство порогу прерывают участок. Отчёт содержит значения обоих порогов, число принятых интервалов и участков, их суммарную и максимальную непрерывную длительность. Без двух введённых порогов показатель остаётся пустым. Изменения внутри интервала между отсчётами требуют другой временной разрешающей способности. Отнесение сигналов к двум разным физическим выходам подтверждает лаборатория в протоколе опыта.
