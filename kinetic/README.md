# KINETIC — Анатомия движения

Интерактивный 3D-атлас протеза ноги, созданный для Технопарка РГСУ.

- Перетаскивайте модель мышью для вращения.
- Прокручивайте колёсико или двигайте нижний ползунок для раскрытия накладок и разнесения узлов.
- Нажимайте на накладки и точки, чтобы исследовать конструкцию.
- Shift + колесо, кнопки + / − или жест двумя пальцами изменяют масштаб.
- Режим «В движении» демонстрирует сгибание коленного узла.
- Пробел запускает и останавливает демонстрацию, R возвращает исходный вид.

Есть три варианта покрытия, прозрачные накладки и выбор ракурса.

## Запуск

Сайт статический, сборка и установка зависимостей не нужны. Все библиотеки включены в `assets/vendor/`.

Для локального просмотра запустите HTTP-сервер из этой папки, например `python -m http.server 8000`, и откройте `http://localhost:8000/`.

Для интерактивной сцены нужен браузер с WebGL 2 и аппаратным ускорением.

## О модели

Это авторский демонстрационный концепт. Геометрия и движение упрощены; модель не воспроизводит конкретное медицинское изделие и его расчётные параметры. Исследовательские источники доступны в интерфейсе, в разделе «О модели и источниках».

Three.js 0.180.0 распространяется по лицензии MIT. Текст лицензии сохранён в `assets/vendor/THREE-LICENSE.txt`.


## Показ и резервный режим

- Кнопка «Демо · 30 секунд» проводит через силуэт, раскрытие накладок, разнесение узлов и условное сгибание. Любое ручное действие прерывает сценарий; Esc останавливает его.
- «Сбросить вид» восстанавливает сборку, начальный ракурс, керамическое покрытие, подписи и масштаб. «Собрать» возвращает только раскрытие или угол.
- При недоступном WebGL включается явно обозначенная интерактивная 2D-схема. Она поддерживает раскрытие, движение, выбор узлов, прозрачность, покрытие и масштаб. Свободное вращение и ракурсы доступны только в 3D.
- Для проверки схемы без отключения графического ускорения откройте `?schematic=1`.
- На телефоне страница прокручивается. Перетаскивание самой 3D-модели вращает её; управляющие элементы находятся под сценой.
- Все зависимости находятся в этой папке, внешние CDN и сетевые модели не используются. Перед выступлением всё же откройте страницу и проверьте её на презентационном компьютере: локальная доступность файлов не гарантирует работу без интернета после перезапуска браузера.
