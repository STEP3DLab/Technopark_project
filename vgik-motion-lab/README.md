# КАДР — виртуальная студия РГСУ × ВГИК

Демонстрационный 3D-прототип для разработки роботизированной съёмочной установки Технопарка РГСУ. В студии можно поставить сцену, запрограммировать движение руки с камерой ключевыми позами и получить последовательность кадров для покадровой анимации.

**Демонстрация:** [открыть студию](https://step3dlab.github.io/Technopark_project/vgik-motion-lab/).

## Что умеет прототип

- Показывает роботизированную руку с шестью регулируемыми осями, шарнирами, крепежом и камерой на конце манипулятора.
- Даёт общий обзор сцены с вращением и приближением, просмотр через камеру робота и отдельный монитор кадра 16:9.
- Содержит три объекта съёмки: маленький робот с анимируемой позой, макет ракеты и абстрактная композиция.
- Предлагает три программы для быстрого показа: облёт объекта, плавный наезд и подъём камеры.
- Позволяет задавать углы суставов, наклон и крен камеры, фокусное расстояние и позу персонажа; записывать, изменять и удалять ключевые позы.
- Интерполирует движения плавно, линейно либо с удержанием позы до следующего ключа. Для покадрового просмотра есть переход на следующий кадр.
- Меняет схему света, отображает траекторию, сетку площадки, поле зрения и композиционную сетку монитора.
- Снимает отдельные изображения или весь проход программы, воспроизводит снятые кадры и сохраняет PNG одним ZIP-архивом.
- Сохраняет проект в браузере, импортирует и экспортирует JSON и показывает читаемую текстовую программу виртуального стенда.

## Демонстрация за две минуты

1. Откройте студию и нажмите **«Запустить демо»**. Слева выберите готовое движение камеры; на мониторе справа виден получаемый кадр.
2. Переключитесь на **«Через камеру»**, чтобы показать съёмочный ракурс крупно. Вернитесь в **«3D-студию»**, чтобы объяснить работу манипулятора.
3. Остановите движение и выберите время на шкале. Измените, например, основание и плечо робота, объектив или позу персонажа. Нажмите **«Сохранить ключевую позу»**.
4. Запустите программу снова: робот пройдёт через сохранённые положения. При включённом **«Следить за объектом»** камера автоматически направляется на объект; запястье и наклон задают смещение кадра.
5. Откройте **«Снятые кадры» → «Снять всю программу»**. После съёмки нажмите **«Просмотреть»**, затем **«Скачать кадры»**.
6. Для продолжения работы на другом устройстве выберите **«Проект» → «Сохранить проект»**. Полученный JSON открывается командой **«Открыть проект»**.

## Управление

| Действие | Управление |
| --- | --- |
| Вращение общего вида | Перетаскивание мышью или одним пальцем |
| Масштаб | Колесо мыши или жест двумя пальцами |
| Пуск / пауза | Кнопка воспроизведения или пробел |
| Запись ключевой позы | Кнопка сохранения или `K` |
| Снимок текущего кадра | «Снять кадр» или `C` |
| Предыдущий / следующий кадр | Стрелки влево / вправо |
| Выбор ключевой позы | Ромб на временной шкале |
| Отмена изменения проекта | «Отменить действие» |

Горячие клавиши не перехватывают ввод в полях и диалогах. На узком экране панели перестраиваются вертикально.

## Проекты и кадры

Проект хранит позы, время, частоту кадров, тип перехода и настройки сцены. Он автоматически сохраняется в `localStorage` этого браузера. Для переноса или резервной копии используйте экспорт JSON. Изменённую вручную позу нужно записать кнопкой **«Сохранить ключевую позу»**.

Изображения снимаются в **1280 × 720** без интерфейса и вспомогательной сетки. За один проход допускается до **360 кадров**; при превышении лимита нужно уменьшить длительность или частоту. Полный проход включает конечную позу как дополнительный опорный кадр. Для точной длительности ролика этот последний кадр можно исключить при сборке последовательности.

ZIP содержит PNG по порядку, таблицу времени `frames.csv`, JSON проекта и пояснение. Галерея снятых кадров хранится в памяти страницы: скачайте архив до перезагрузки или закрытия вкладки. Видео MP4 не кодируется; последовательность PNG можно собрать в видеоредакторе.

## Границы демонстратора

Это виртуальный учебный стенд. Геометрия, размеры и диапазоны суставов служат демонстрации принципа. Модель не является конструкторской документацией для изготовления, а программа не управляет реальными приводами. Автонаведение реализовано для визуальной постановки кадра. Расчёт нагрузок, столкновений, динамики, калибровка и протокол связи с контроллером относятся к дальнейшему инженерному этапу.

## Устройство проекта

Статическое приложение HTML/CSS/JavaScript без сборки и серверной части. Three.js **r180** и `OrbitControls` находятся в `vendor/`; при запуске не требуется CDN. Геометрия сцены и текстуры создаются программно. Нужен браузер с JavaScript и WebGL 2.

| Файл | Назначение |
| --- | --- |
| `index.html`, `styles.css` | Интерфейс и адаптивная вёрстка |
| `main.js` | Управление студией, проектом и съёмкой |
| `scene.js` | 3D-сцена, робот, камеры и освещение |
| `motion.js` | Ключевые позы, интерполяция, проверка JSON и экспорт программы |
| `zip.js` | Подготовка ZIP-архива кадров |
| `motion.test.mjs` | Проверки модели движения и импорта |
| `vendor/` | Локальные зависимости и лицензия Three.js |
| `assets/` | Брендовые изображения |

Локальный запуск из этой папки:

```sh
python -m http.server 8000
```

Затем открыть `http://localhost:8000/`. Загрузка напрямую через `file://` не подходит для модулей JavaScript.

Проверки модели:

```sh
npm test
```

Папка публикуется в составе существующего репозитория `STEP3DLab/Technopark_project` через GitHub Pages. Для работы приложения достаточно статической раздачи файлов.

## Бренд и исходная концепция

Логотип РГСУ перенесён без изменений из ранее опубликованных материалов этого репозитория: `industrial-design-lab/assets/brand/rgsu-blue.svg` и `rgsu-white.svg`. Основные цвета: синий, тёмно-синий, белый и акцентный малиновый. Концепция опирается на слайд «Механизмы для ВГИК»: камера для покадровой анимации, 3D-печатные звенья и корпуса, металлические оси и крепёж.

Three.js распространяется по лицензии MIT; текст находится в `vendor/THREE-LICENSE.txt`.
