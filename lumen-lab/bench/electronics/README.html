Двухканальный USB-термометр LM-04B

Плата принимает показания двух внешних DS18B20+ через отдельные шины 1-Wire. Контакты питания общие. Версия B — измерительный стенд на исходной Raspberry Pi Pico RP2040. Габариты носителя 80 × 52 × 1,6 мм. Верхняя сторона платы обращена к наблюдателю, USB находится слева.

Скопируйте всю папку electronics перед открытием проекта KiCad. Положите рядом со схемой таблицы библиотек, файл LM04.kicad_sym и папку LM04.pretty. Стандартные библиотеки KiCad предоставляют корпус осевого резистора DIN0207 и монтажные отверстия.

Разъёмы

Сигнал Pico J2, T1 J3, T2 DS18B20+ TO-92
Питание 3,3 В 36, 3V3_OUT 1 1 3, VDD
Данные T1 4, GP2 2 — 2, DQ первого датчика
Данные T2 5, GP3 — 2 2, DQ второго датчика
Земля 38, GND 3 3 1, GND

У каждого сигнала DQ собственная подтяжка 4,7 кОм к 3,3 В. Контакты со стороны южной кромки к северной на обеих клеммах идут в порядке V, D, G. Нумерацию DS18B20+ проверяют при плоской грани к наблюдателю и ножках вниз. Слева направо расположены GND, DQ, VDD. Питание подаётся по USB на Pico.

Посадочные размеры

Начало декартовых координат находится в юго-западном углу платы. Четыре неметаллизированных отверстия диаметром 3,2 мм расположены на 5 мм от каждой пары ближайших сторон. Первый контакт Pico находится в точке (2,37; 17,11), сороковой — в точке (2,37; 34,89). Центры клемм J2 и J3 равны (71; 16,5) и (71; 35,5). Винты доступны сверху, провода входят с востока. Розетки Harwin установлены на носителе, ответные штыри припаяны к модулю. Ведомость механических креплений приведена в документации корпуса.

Проверка проекта

Для сохранённых файлов KiCad 9.0.2 выдал 0 нарушений ERC, 0 нарушений DRC, 0 незамкнутых цепей и 0 расхождений между схемой и платой. Отчёты drc.json и erc.json находятся в папке reports. Отдельная проверка connectivity.json проходит по медным дорожкам обоих слоёв и металлизированным площадкам. Она сопоставляет четыре функциональные цепи с независимым перечнем выводов, экспортом электрической схемы и сверловкой. Остальные 36 выводов Pico помечены на схеме как незадействованные и имеют отдельные изолированные площадки.

Изготовление, пайка, проверка размеров разъёмов и измерение температуры реальными датчиками предстоят. Руководство содержит порядок проверки первого экземпляра. Инструкции для прошивки и записи измерений находятся в корне комплекта B.

Перегенерация

В каталоге sources находятся генераторы проекта. Для сборки с уже установленными KiCad 9, Python с pcbnew и отдельным Python с PyMuPDF и ReportLab выполните команду bash sources/rebuild.sh из этой папки. Путь к Python для документации можно передать в DOC_PYTHON, к Python с KiCad в KICAD_PYTHON. Скрипт перезаписывает файлы проекта по генераторам. Сохраните отдельно внесённые вручную изменения перед перегенерацией.
