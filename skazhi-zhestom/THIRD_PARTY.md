# Материалы проекта

- Иллюстрации котиков созданы для проекта с помощью генерации изображений в ChatGPT. В репозитории находятся готовые PNG; внешняя генерация не нужна для работы приложения и локального рендера.
- Движение создаётся локальным растровым деформатором (`renderer/cat/rig.mjs`, `scripts/render-cat-motion.mjs`) и кодируется FFmpeg. Это не полноценная 3D-анимация и не проверенный перевод РЖЯ.
- Шрифт Manrope распространяется по SIL Open Font License 1.1. Копия лицензии: `fonts/Manrope-OFL.txt`.
- Для необязательного повторного рендера используется Sharp (Apache-2.0) и установленный пользователем FFmpeg. Их исполняемые файлы не входят в репозиторий.
- На сайте нет удалённых шрифтов, трекеров, платных SDK и CDN-зависимостей.
