# Рельефная карта Беларуси

[Производственный сайт](https://step3dlab.github.io/Technopark_project/belarus-relief/) · [Комплект для мастерской](https://step3dlab.github.io/Technopark_project/belarus-relief/downloads/belarus-production.zip)

Утверждённый вариант с красным задником, шестью зелёными областями, шестью рубиновыми звёздами, бронзовыми надписями, зубром в Брестской области и цветочной лентой.

## С чего начать

1. Откройте **print/workbook.pdf**. Лист 2 содержит состав и габариты, листы 3–6 — восемь операций с критериями приёмки.
2. Печатайте **templates/assembly-a4.pdf** при масштабе 100%. Совместите кресты на четырёх листах A4 и проверьте 50-миллиметровую шкалу.
3. Загружайте по одной области из **models/regions/** в слайсер FDM в масштабе 100% и в миллиметрах. Для раздельной печати центрируйте область на столе. Все STL используют общее начало координат для контрольной сборки.
4. Откройте **models/decor-plate.3mf** в слайсере для мелких деталей. Файл содержит 13 экземпляров: 6 названий, 6 звёзд и зубра. Реальная раскладка 105,67 × 68,42 мм, рекомендуемое доступное поле от 115 × 75 мм. Для MSLA настройте ориентацию и поддержки под свой принтер и смолу. Выбор профиля, проверку первого слоя/экспозиции и генерацию машинного кода выполняют в слайсере конкретной машины.
5. Для рамы используйте **print/frame.pdf**, для ленты — **print/sash-1to1.pdf** на A3. Сухая примерка предшествует склеиванию. Лента в базовой смете — сублимационная печать по сатину. Заказ ручной или машинной вышивки требует отдельной оцифровки стежков и оценки стоимости.
6. Расход, цену и тираж изменяйте в **downloads/specification.xlsx**. Открытые параметры и прайсы также находятся в **data/budget.json**. Заводские испытания и фактический хронометраж не выполнялись.

## Основные величины

| Параметр | Значение |
|---|---|
| Карта | 357,904 × 309,056 мм |
| Шкала рельефа | 12 мм сверх базовых 4 мм |
| Фактический максимум детали области после подготовки площадок | 14,627 мм |
| Задник / наружная рама / световой проём | 420 × 390 × 6 / 450 × 420 / 410 × 380 мм |
| Четверть рамы | 6 × 9 мм с тыльной стороны |
| Шов между областями | ориентир 0,85 мм |
| Габарит ленты | 340 × 38 мм с бахромой |
| Состав | 19 печатных изделий на панно; 16 уникальных STL |
| Номинал звезды | Минск 17 мм, Гомель 14 мм, другие города 12 мм |

Мастер **models/panel.glb** объединяет раму, задник, карту, звёзды, надписи, барельеф и ленту. glTF использует метры, STL/3MF — миллиметры. Брестский знак технологически сдвинут на 4,5 мм к востоку для опоры луча. Измеренное рельефное основание исходного художественного проекта приведено к относительной шкале. Происхождение и ограничения описаны в [перечне источников](source/RELIEF-SOURCES.md).

## Пересборка и настройка высоты

Исходник поверхности и шести контуров, векторные профили и скрипты хранятся в **source/**. В Python 3.11+ установите зависимости из **source/requirements.txt**. Для повторного экспорта орнамента в PDF/PNG нужен Inkscape; в комплекте есть и готовые файлы. Выполняйте из корня отдельной рабочей копии.

```bash
python source/build_decor.py --seats-only
python source/build_terrain.py --relief 12
python source/build_decor.py
python source/build_bison.py
python source/build_decor_plate.py
python source/build_assembly.py
python source/build_assembly.py --compact
python source/estimate_fdm.py
```

Измените число после **--relief**, чтобы получить другое вертикальное усиление. Нижняя плоскость остаётся на Z=0, размер XY сохраняется. Пересобирайте декор, площадки и GLB в указанном порядке, чтобы опорные уровни совпадали. Для новых высот пересчитайте расход, время и фактические размеры в документации перед производством. Подготовленный пакет рассчитан для среднего положения 12 мм.

Паспорта и посадочные координаты находятся в **data/**. Код шрифтов, Three.js и данные о происхождении географии сопровождаются лицензиями и атрибуциями в **source/fonts**, **vendor** и **assets** репозитория.
