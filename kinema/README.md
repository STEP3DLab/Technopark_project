# KINEMA 2.0 — интерактивный атлас кинематики

Адаптивный самостоятельный сайт для изучения кинематики на русском языке. Монохромная графика и инженерные механизмы, рассчитываемые геометрически без внешних библиотек.

## Открыть

`index.html` — стартовая страница. В корне репозитория `STEP3DLab/Technopark_project` доступен по адресу https://step3dlab.github.io/Technopark_project/kinema/ . Автономная версия для открытия без сервера — `offline.html`.

## Возможности

- **6 механизмов:** кривошип–ползун, четырёхзвенник, зубчатая передача, кулачок, кулиса, робот 2R.
- **8 кинематических пар:** R, P, C, S, U, H, E, F, с 3D-моделями, переменными и ограничениями.
- **Три режима графиков:** положение q, скорость dq/dt, ускорение d²q/dt². Угловая скорость входа по умолчанию 54°/с и масштабируется регулятором скорости; ускорение входа предполагается нулевым.
- **Обратная задача 2R:** целевая точка (X,Y), конфигурация «локоть вверх / вниз», сообщение о недостижимости и оценка сингулярности через det J.
- **6 экспериментов:** проверка числового ответа и параметров модели, локальное сохранение выполненных опытов.
- **16 вопросов:** объяснение после каждого ответа, сохранение результата, повторная попытка.
- **Калькулятор подвижности:** формула M = 3(n−1) − 2j₁ − j₂ для плоской структурной схемы при независимых ограничениях.
- **Клавиатура и мобильные устройства:** выбор вкладок стрелками; поддержка жестов для 3D, учёт настроек уменьшения движения.

## Запуск и разработка

Откройте `index.html` напрямую или запустите `python -m http.server 8000` в этом каталоге. Нет сборки, сервисов, трекеров, загрузки шрифтов, внешних JS и CSS.

## Границы корректности

- Модели идеализированы: не учитывают силы, упругость, трение и люфт.
- Зубчатые зубцы условны, это не модель зацепления с эвольвентными профилями.
- Кулачок — круговой эксцентрик с идеальным контактирующим роликом; динамика толкателя не рассчитывается.
- Пространственные шарниры — схематическая визуализация степени свободы, не производственные CAD-модели.
- Плоская формула структурной подвижности предполагает независимые связи. При специальных геометриях или избыточных ограничениях требуются уравнения замыкания и анализ ранга.
- Численные скорости/ускорения вычисляются центральными разностями по углу с h = 0.001 рад, при постоянной скорости входного звена. Это иллюстрационные расчёты, не замена точной аналитической верификации.
