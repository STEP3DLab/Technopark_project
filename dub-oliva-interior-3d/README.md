# Дуб и олива — интерьер квартиры

Официальный исходный сайт: https://dub-oliva-interior-3d.step3d.chatgpt.site/

GitHub Pages: https://step3dlab.github.io/Technopark_project/dub-oliva-interior-3d/

Сайт с фотореалистичными рендерами, 360°-панорамой, интерактивной 3D-моделью квартиры в формате GLB, эскизами и планом. Стиль: mid-century modern; палитра — натуральный дуб, оливковый и терракота.

## Публикация

Файл mirror.py переносит публичную HTML-страницу и локальные изображения, сценарии, стили и модель GLB с исходного сайта в эту папку, исправляя абсолютные пути для GitHub Pages. Workflow .github/workflows/publish-dub-oliva.yml запускается при загрузке и поддерживает ручной перезапуск. После первого успешного запуска создается MIRROR_REPORT.json с перечнем перенесённых файлов и диагностикой. До завершения переноса используется временное встраивание исходного сайта через iframe. Для обновления зеркала можно запустить workflow повторно.
