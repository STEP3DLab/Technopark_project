LM-04B. От комплекта деталей до записи измерений

Этот комплект предназначен для изготовления отдельного двухканального регистратора температуры. Для первого опыта нужны оригинальная Raspberry Pi Pico на RP2040 с 2 МиБ Flash, два DS18B20+ с внешним питанием, два резистора 4,7 кОм и USB-кабель Micro-B с линиями данных. Исполнение B получает питание от компьютера. Датчики могут работать на лабораторном образце и по отдельности сообщают об отказе.

Подготовить электронику

  1. Сверьте детали с ведомостью электроники. Для проверки на столе используйте макетную плату и схему на четвёртой странице руководства по монтажу. Сначала соберите электрическую часть без корпуса.
  2. Для печатной платы передайте изготовителю архив Gerber и Excellon. Монтаж следует принципиальной схеме и карте размещения. В составе Gerber есть отдельные файлы металлизированной и неметаллизированной сверловки.
  3. Установите по одному датчику на J2 и J3 при отключённом USB. На обеих клеммах контакт 1 — VDD 3,3 В, контакт 2 — DQ, контакт 3 — GND. Прозвоните питание, землю и обе независимые цепи данных по перечню соединений. Цвет жил зависит от производителя кабеля.
  4. Если требуется корпус, распечатайте лоток и крышку. Установите крепёж из механической ведомости. Порядок монтажа, точки крепления кабеля и этикетки в масштабе 1:1 приведены в сборочном руководстве.

Загрузить прошивку и получить два канала

Проверьте маркировку платы. Полный образ рассчитан на исходную Raspberry Pi Pico RP2040 с 2 МиБ Flash. Он заменяет всю Flash, включая находившиеся там файлы. Если на плате уже есть нужные программы, предварительно сохраните их. Для совместимой существующей установки MicroPython 1.25.0 предусмотрена установка только приложения с чтением обратно.

  1. На отключённой оригинальной Pico удерживайте BOOTSEL и подключите USB. После появления диска RPI-RP2 отпустите кнопку. Скопируйте LM04B-Pico-v1.uf2 целиком на диск. Дождитесь автоматического перезапуска. SHA-256 файла указан в руководстве по прошивке и в SHA256SUMS комплекта.
  2. Откройте журнал в настольном Chrome или Edge. Нажмите «Подключить Pico по USB» и выберите порт. Порт должен быть свободен от Thonny и других терминалов. Наличие подключения видно по номеру платы, запуска и приходящим кадрам. Без подключённого датчика его канал передаёт статус отсутствия.
  3. Снимите не менее 60 последовательных кадров с двумя датчиками рядом при стабильной комнатной температуре. Зафиксируйте номера датчиков и условия. Сопоставьте показания с независимым термометром и внесите в бланк приёмки показания и сведения о контрольном приборе. Выбор допустимого отклонения зависит от требуемой точности опыта и неопределённости средств измерения.
  4. Проверьте каналы по отдельности. Отключайте USB перед перестановкой проводов. Оставьте T1 подключённым, временно снимите T2 и начните новый сеанс. T1 должен вернуть правильные кадры, T2 — статус отсутствия. Повторите для противоположной стороны. Реальные отказы соединений и их причины фиксируют в бланке.
  5. Остановите запись. Укажите номер опыта, прибор и документ о калибровке в разделе «Качество данных и реквизиты опыта». Скачайте запись JSONL и отчёт JSON. После повторного открытия JSONL число кадров, диапазоны и пропуски должны совпасть. Поле normalizedDataSha256 в отчёте относится к нормализованной выгрузке, поле originalFileSha256 — к байтам импортированного файла.

Для компьютеров без Web Serial предусмотрен консольный регистратор. Программа открывает новый файл и сохраняет каждый полный кадр по мере получения. Это удобно для длительного опыта. Опыт из браузера хранится в памяти вкладки до выгрузки.

Что измеряет стенд

Показания T1/T2 описывают температуру в местах установки датчиков. Плата не измеряет оптическую мощность. Корпус TO-92 и проводка из ведомости рассчитаны на сухой стенд. Разрешение цифрового отчёта не задаёт погрешность измерительного узла.

Для записей внешних измерителей мощности в журнале предусмотрен формат CSV с общей временной шкалой. По нему вычисляются покрытие и интеграл мощности каждого канала. При введённых порогах различимости программа отдельно показывает участки, на концах которых оба сигнала выше порогов. Для идентификации участков сторона, проводившая опыт, указывает физический выход, серийный номер измерителя, калибровку и источник времени. Температурный график и учебные CSV не подтверждают параметры медицинского аппарата.

Воспроизвести цифровые проверки

  • Плата и схема — проект KiCad и отчёты.
  • Печатные детали и посадка — CAD и результаты геометрических проверок.
  • Загрузочный образ, эмулятор и исходник — описание прошивки.
  • Численная обработка, журнал и USB-поток — из папки bench выполните node --test checks/*.test.mjs. Для тестов настольной программы установите PySerial 3.5 и выполните python -m unittest discover -s checks -p test_recorder.py -v. Для проверки зависимостей полной прошивки используйте её собственное руководство.
  • Локальный запуск журнала из распакованного каталога LM-04B — python -m http.server 8000. Откройте http://localhost:8000/bench/ в браузере. Сеть нужна для внешних первоисточников.

Проверенный экземпляр программного комплекта

Полный UF2 запустился в эмуляторе RP2040 с цифровыми моделями двух DS18B20. В четырёх кадрах зафиксированы чтение обоих каналов, отключение и замена датчика, отбрасывание неоднозначного значения +85 °C и восстановление. Сохранённый журнал помечен как данные эмулятора. В сквозном испытании исходные кадры с виртуального USB были переданы через псевдотерминал реальному консольному регистратору PySerial. Содержимое записанного файла побайтно совпало с выходом прошивки. Браузер открыл результат и показал независимые статусы обоих датчиков. Сценарий воспроизведения принимает пути к RP2040js и bootrom из руководства по прошивке.

Всего успешно выполнено 47 автоматических тестов журнала, вычислений, записи, прошивки и загрузочного образа. Эта проверка проведена на программном комплекте. Пункты бланка для электрического, механического и метрологического приёмочного контроля физического образца остаются открытыми.

Приёмка медицинской части

Для исходного проекта подготовлены сравнение готовых аппаратов и запрос о предоставлении конкретного исполнения и протокола. Комплект B позволяет отдельно принять регистратор. Для подтверждения характеристик аппарата по исходному ТЗ нужны изготовитель с подходящим исполнением, физический экземпляр, согласованные измерения на фантоме и протокол по фактическим данным.
