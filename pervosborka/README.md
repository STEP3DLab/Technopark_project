# ПЕРВОСБОРКА — Технопарк РГСУ

Интерактивная профориентационная экспедиция: карточки интересов, ситуации и восемь практических лабораторий.

**Открыть приложение:** https://step3dlab.github.io/Technopark_project/pervosborka/

## Возможности

- Большая экспедиция: 48 карточек, 8 ситуаций, 8 лабораторий.
- Короткий маршрут: 16 карточек, 2 ситуации и любые 2 лаборатории.
- Управляемые 3D-сцены, изменение параметров конструкции, программирование маршрута робота и другие практические задания.
- Режим «Только задание», обзор карточек с поиском и фильтрами, возвращение к незавершённым действиям.
- Компактный паспорт результата, подробная карта, подготовка карточки SVG и снимка 3D в PNG.
- Сохранение работы в текущем браузере, перенос через JSON, печать результата.

Регистрация, камера и микрофон не нужны. Изображения, скрипты и стили встроены в стартовый HTML; приложение не зависит от CDN.

## Структура

- `index.html` — автономная сборка для прямого запуска на GitHub Pages.
- `dist/` — модульные исходники приложения, графические ресурсы и автономная сборка.
- `tests/` — 23 файла автоматических проверок.
- `build-offline.py` — сборка автономного HTML из модульной версии.

Стартовый `index.html` совпадает с `dist/pervosborka-offline.html`.

## Локальный запуск и проверка

Откройте `index.html` в браузере. Модульную версию можно открыть через локальный статический сервер из `dist/`.

```bash
node --test tests/*.test.cjs
python3 build-offline.py
cp dist/pervosborka-offline.html index.html
```

При подготовке редакции от 30 октября 2026 года пройдены 259/259 автоматических проверок; проверен синтаксис 20 скриптов. Автономная сборка включает 20 JS- и 22 CSS-файла.

В проверочном браузере подтверждена подготовка PNG/SVG, но получение скачанных файлов средой проверки не подтверждено. Аппаратный GPU и физические мобильные устройства отдельно не проверялись.
