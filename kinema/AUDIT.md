# KINEMA 2.0 — аудит по четырём экспертным ролям

Дата проверки: 18 ноября 2026 года. Это **ролевой экспертный аудит**, выполненный с четырёх профессиональных позиций. Он не означает, что четыре независимых человека лично участвовали в тестировании.

## 1. Инженер-кинематик — точность геометрии и терминов

| Приоритет | Наблюдение исходной версии | Выполненная доработка |
|---|---|---|
| P0 | У ведомого зубчатого колеса возникал скачок фазы после оборота ведущего: угол θ искусственно приводился к периоду 2π, хотя для нецелого отношения зубьев ведомое колесо ещё не завершило собственный цикл | Внутренний угол сохраняется непрерывным; позиция регулятора выводится по модулю 360°. График Δφ₂ подписан как *один оборот входа*, а не абсолютное положение |
| P1 | Для двухзвенного манипулятора отображалась только прямая кинематика | Введена аналитическая обратная задача для целевой точки (X,Y): две ветви положения локтя, проверка достижимости R ∈ [28,252] мм, углы θ₁ и θ₂, контроль ошибки |
| P1 | Не было показано, что в некоторых положениях матрица скоростей вырождается | Добавлена диагностика det J = l₁l₂ sin θ₂ и объяснение особых положений в теоретическом разделе |
| P2 | Графики отражали лишь положение | Добавлены графики скорости и ускорения как численные производные геометрической кинематики при постоянной входной угловой скорости; указаны единицы и ω |
| P2 | Показатель отношения шестерён использовался без явного знака | В интерфейсе показан именно модуль `|i|`; знак направления указан в формуле `ω₂/ω₁ = −z₁/z₂` |

**Модельные допущения:** четыре звена четырёхзвенника и шатун ползуна рассчитываются по уравнениям замыкания; условия трения, люфтов, упругости и реального профиля зубьев не реализованы. Пространственные соединения — схематические 3D-модели, не CAD для производства. Численное дифференцирование с шагом 0,001 рад не заменяет аналитических производных в исследовательском расчёте.

## 2. Преподаватель технических дисциплин — понимание через действие

| Приоритет | Наблюдение | Доработка |
|---|---|---|
| P1 | Пользователь мог просмотреть красивые анимации без проверки, способен ли применять зависимости | Добавлены шесть числовых экспериментов, по одному для каждого механизма. Для части заданий проверяется и ответ, и положение/параметры модели |
| P1 | Заключительное занятие можно было произвольно отметить завершённым | Зачёт выставляется только автоматически при результате не ниже 13 из 16 вопросов |
| P2 | Переход от положения к скорости и ускорению не был представлен визуально | Единый расчётный график q/v/a, мгновенная обратная связь при изменении скорости |
| P2 | Недостаточно разбирались реальные сложности обратной кинематики | Добавлены условия достижимости, две конфигурации локтя и особые положения |

**Учебная рекомендация:** проходить разделы в порядке «свободы → пары → механизм → графики → числовой эксперимент → зачёт», затем повторить задания с другими параметрами. Автоматическая отметка подтверждает лишь результат этого практикума, не профессиональную квалификацию.

## 3. UX/UI-дизайнер — управляемость и визуальная иерархия

| Приоритет | Наблюдение | Доработка |
|---|---|---|
| P1 | На телефоне основные навигационные пункты скрывались, а страница длинная | Добавлена фиксированная нижняя мобильная навигация по пяти разделам |
| P1 | Сложно понять связь между кривой и физической величиной | Появились переключатели «положение / скорость / ускорение», единицы измерения и угловая скорость привода |

## 4. Frontend-разработчик и QA — функциональность, устойчивость, доступность

Протестировано в Chromium через Playwright на **1440×900** и **390×844**:

- Все шесть механизмов × три графика, во всех проверенных точках значения конечны.
- Проверена непрерывная фаза зубчатой передачи после перехода θ через 360°.
- Проверены переключение вкладок с клавиатуры, ввод задания, успешная обратная задача 2R, недостижимая точка, все 16 ответов викторины, выбор вращательной и жёсткой кинематических пар, пресеты калькулятора.
- Для 361 положения кривошипа проверялись ограничения: длина шатуна ползуна и две длины звеньев четырёхзвенника. **Максимальный модуль невязки: 1,14×10⁻¹³ мм** (округление double-precision).
- Ошибка обратной кинематики при цели X=140 мм, Y=112 мм — **0 мм на проверенном наборе** (в вычислениях double-precision).
- Ошибок JavaScript: **0** на обоих размерах экрана; горизонтальное переполнение: **0 px**.
- Отработали локальная память прогресса и интерфейс с активными параметрами (для браузерного прогона использован in-memory аналог `localStorage`).

Тестировалось автономное представление страницы через `page.set_content()`, поскольку локальная навигация браузера в доступном тестовом окружении ограничена. Онлайн-публикация на GitHub Pages дополнительно проверяется отдельно. Протокол повторяемых браузерных тестов см. `tests/smoke.py`.

## Ограничения и следующий инженерный этап

1. Добавить ввод произвольных размеров для четырёхзвенника и обнаружение несуществующих сборок.
2. Показать диаграмму скоростей, мгновенный центр скоростей и якобианы для нескольких механизмов.
3. Добавить силовой анализ и объяснение отличия кинематики от динамики.
4. Реализовать производственные 3D-модели соединений с ограничениями, зазорами и параметрическими CAD-элементами.
5. Расширить банк заданий задачами с числовым допуском, ветвями сборки и развёрнутыми вычислениями.

**Итог:** KINEMA 2.0 — рабочий учебный атлас базовой кинематики, не универсальный CAD-решатель и не заменитель полного курса теоретической механики.
