# Лаборатория промышленного дизайна и инжиниринга — Технопарк РГСУ

Самостоятельная адаптация актуального сайта STEP_3D для лаборатории Технопарка РГСУ. Исходный сайт STEP_3D не изменён.

Сайт: https://step3dlab.github.io/Technopark_project/industrial-design-lab/

## Содержание

- Главная страница: направления работы, реальные проекты, практика, процесс, контроль качества и контакты.
- 8 страниц направлений.
- Каталог с фильтрацией и 11 отдельных кейсов с фотографиями; кейс костюма содержит два видео процесса.
- Страницы команды, участия студентов и работы формы обращения.
- Оригинальные логотипы РГСУ из предоставленного архива «01 Логотип.zip». Цвета и пропорции сохранены, SVG не изменены.

## Редактирование

`node build.mjs` пересоздаёт все 24 HTML-страницы и sitemap. Node.js 18+; внешние зависимости не нужны.

`data/` — материалы кейсов и направлений. `assets/step3d-base.css` — основа оформления исходного сайта; `assets/lab.css` — адаптация к РГСУ. `assets/lab.js` — мобильное меню, фильтры, увеличение фотографий, подготовка обращения.

Относительные ссылки позволяют работать в подпапке GitHub Pages. При переносе обновите константу `SITE` в `build.mjs`, затем запустите сборку.

## Обращения

GitHub Pages обслуживает статические файлы. Форма готовит текст письма на `ganshinvk@rgsu.net`, открывает почтовое приложение по отдельному нажатию, позволяет скопировать или скачать текст. Автоматической отправки, серверной базы заявок, CRM и загрузки вложений нет. Вложения пользователь добавляет в почтовом приложении. Форма не сохраняет персональные данные в браузерное хранилище.

Визуальная основа, структура направлений и портфолио: сайт STEP_3D, версия 61, исходный коммит `2455797b5c2b1c0c02f90519beab1b2edfdfc482` (15 октября 2026 — дата получения).

Сведения о лаборатории и команде сверены со страницей https://technopark-rgsu.ru/skb/laboratories/industrial-design-engineering/ и контекстом владельца. Контакты сверены с https://technopark-rgsu.ru/contacts/. Учебный кейс: https://technopark-rgsu.ru/skb/cases/table-motion-sensor/.

Проекты, представленные Технопарком, и остальной опыт команды STEP_3D подписаны отдельно. Сохранены имена авторов и исходные ссылки. Публичные описания не заменяют договорные условия; стоимость, этапы, передача исходников и конфиденциальность согласуются индивидуально.

## Проверка

`node --check assets/lab.js` — синтаксис взаимодействий. `python3 scripts/check-site.py` — внутренние ссылки, ресурсы, якоря, заголовки и подписи полей (нужен lxml). `node scripts/check-interactions.cjs` — проверка сценариев меню, фильтров, галереи и подготовки письма в изолированной модели DOM.

Проверка в реальном браузере в среде выполнения была недоступна. Макеты содержат правила для мобильных, планшетных и больших экранов; визуальная проверка на устройствах остаётся отдельным этапом.
