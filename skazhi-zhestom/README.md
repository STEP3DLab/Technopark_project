# Скажи жестом · MVP 1.0

Шесть анимированных котиков: жест и слово в одном стикере. Каталог работает без регистрации, сервера приложения и платных API.

**Открыть приложение:** https://step3dlab.github.io/Technopark_project/skazhi-zhestom/

![Котик «Привет!»](cat-motion/hello-poster.webp)

## Что работает

- Шесть циклических анимаций с прозрачным фоном и встроенными русскими подписями.
- Поиск по словам и синонимам, фильтр поддержки, избранное с сохранением на устройстве.
- Просмотр на светлом и тёмном фоне, пауза, скорость 0,5× / 1× / 1,5×, учёт настройки уменьшения движения.
- Скачивание WebM и PNG; ZIP всего набора или избранного создаётся прямо в браузере.
- Ссылки на отдельные реакции: `?sticker=hug`. Отправка файла через системное меню, если браузер поддерживает Web Share Files.
- Установка PWA на главный экран и явное сохранение всех файлов для работы без интернета.
- Локальный Telegram-бот: выбор реакции → стикер и текст; знакомый стикер → его значение.
- Скрипт публикации Telegram-набора через собственный бот.

Сайт можно использовать сразу. Telegram-бот и общий набор **не запущены**: для них владелец локально задаёт токен BotFather. Пока ссылка набора не настроена, сайт показывает рабочее скачивание и инструкцию для @Stickers.

Это художественные реакции, **не учебный словарь русского жестового языка**. Движения не проверены носителями РЖЯ. Котики — растровые иллюстрации с программной анимацией; полноценной 3D-модели в проекте нет.

## Локальный запуск

Из этой папки:

```sh
python3 -m http.server 8000
```

Открыть http://localhost:8000/. Сборка и установка пакетов для просмотра не нужны. Не открывать `index.html` через `file://`: каталог загружается через HTTP.

GitHub Pages уже может отдавать проект из подпапки репозитория: все пути относительные. PWA работает по HTTPS или на localhost. Для офлайн-доступа сначала нажать **«Сохранить офлайн»** и дождаться подтверждения. Браузер может удалить кэш при очистке данных или нехватке места.

## Проверки

Нужны Node.js 20+, Python 3.10+ и FFmpeg с `ffprobe`:

```sh
npm run build
npm test
npm run check:bot
python3 telegram/bot.py --check
python3 telegram/publish_pack.py
```

Последняя команда без `--publish` только проверяет файлы: не подключается к Telegram и не публикует набор. Тесты покрывают поиск, избранное, ссылки, бинарный ZIP, офлайн-диапазоны, целостность ресурсов, параметры видео и сценарии бота с подменённым API.

## Telegram

Пошаговый запуск: [telegram/README.md](telegram/README.md). Токен хранится только в переменной окружения на машине владельца. Не вставлять его в `config.json`, браузерный код, GitHub или публичные сообщения.

После публикации набора установить `telegramPackUrl` в `config.json`, например `https://t.me/addstickers/ИМЯ_НАБОРА`. Тогда инструкция сменится настоящей кнопкой добавления. Для обновления уже установленной офлайн-копии повышать версию кэша в `sw.js` вместе с версией проекта.

## Устройство проекта

| Путь | Назначение |
|---|---|
| `index.html`, `styles.css`, `js/` | Интерфейс без фреймворка и внешних CDN |
| `cat/` | Статичные PNG |

| `tests/` | Автоматические проверки без реальных отправок |

## Пересоздание анимации

Готовые файлы включены в репозиторий. Для изменения движений установить бесплатные FFmpeg и Sharp:

```sh
npm install --no-save sharp@0.35.5
node scripts/render-cat-motion.mjs hello
npm run build
npm test
```

Без аргумента рендерятся все шесть реакций. Параметры лап, головы, моргания и дыхания находятся в `renderer/cat/rig.mjs`. Рендер использует опубликованные PNG 512×512; результат повторного рендера может отличаться от первоначального экспорта из иллюстраций большего разрешения. Ни платные сервисы, ни ключи API для анимации не нужны.

## Данные и ограничения

Нет аналитики, аккаунтов, cookies приложения и базы пользовательских сообщений. Избранное и фон сохраняются в localStorage. Бот сохраняет только техническую позицию получения обновлений и идентификаторы стикеров; работает, пока запущен его процесс. GitHub и Telegram обрабатывают свои обычные сетевые запросы.

Бот распознаёт только известные стикеры этого набора по идентификаторам Telegram. Распознавания произвольных жестов, камеры и автоматического перевода РЖЯ в MVP нет. Художественная версия может стать основой образовательной после работы с носителями языка и проверки каждого жеста.
