# Telegram-бот и набор

Бот запускается локально на Python 3.10+, без установки Python-пакетов, платных API и аренды сервера. Для постоянной доступности процесс и компьютер должны работать. Сайт и скачивание стикеров не зависят от запуска бота.

## 1. Подготовить собственного бота

Создать бота в официальном [@BotFather](https://t.me/BotFather). Токен задать в локальном терминале. Не публиковать токен и не отправлять его в чат.

Для Bash безопаснее прочитать значение без отображения и записи в историю:

```sh
read -r -s -p 'Telegram token: ' TELEGRAM_BOT_TOKEN
export TELEGRAM_BOT_TOKEN
```

Файл `.env.example` показывает имя переменной; автоматической загрузки `.env` нет. Настоящие `.env` и `.state.json` исключены из Git.

## 2. Проверить и запустить

Из корня `skazhi-zhestom`:

```sh
python3 telegram/bot.py --check
python3 telegram/bot.py --run
```

Открыть своего бота в Telegram, отправить `/start` и выбрать котика. Бот пришлёт WebM-стикер и текстовое значение. Если переслать ему этот стикер, он ответит его значением. Для неизвестного файла он честно сообщит, что не знает его. `/whoami` показывает ваш Telegram ID для публикации набора.

Бот обрабатывает только личные чаты. Один токен — один процесс long polling. При активном webhook скрипт останавливается, чтобы не ломать уже работающую интеграцию. В этом случае используйте отдельного нового бота.

Остановить: Ctrl+C. Перезапуск использует `telegram/.state.json`: позицию обновлений и известные идентификаторы стикеров. Это локальное состояние не следует коммитить.

## 3. Опубликовать общий набор (необязательно)

После `/start` и `/whoami` остановить процесс бота. Сначала посмотреть предварительный результат без сети:

```sh
python3 telegram/publish_pack.py
```

Затем, с той же переменной окружения и своим ID вместо `123456789`:

```sh
python3 telegram/publish_pack.py --publish --owner-id 123456789 --name skazhi_zhestom_cats --write-config
```

Скрипт загружает шесть видео через Bot API, создаёт набор, проверяет число стикеров и выводит ссылку. Telegram требует уникальное имя с окончанием `_by_ИМЯБОТА`; скрипт добавляет его сам. Для повторной публикации с другим содержимым задайте новое `--name`: существующий набор не перезаписывается.

`--write-config` записывает только публичную ссылку и имя бота в `config.json`. После этого обновите версию кэша `sw.js` и опубликуйте эти файлы на GitHub, чтобы кнопка сайта открывала созданный набор. Токен в конфигурацию не попадает. После публикации можно снова запустить `bot.py --run`.

Альтернатива без собственного бота: скачать ZIP на сайте и создать набор через официальный [@Stickers](https://t.me/Stickers).

## О формате

Каждый файл: WebM, VP9 с alpha, 512×512, 24 кадра/с, до 3 секунд, без аудио, меньше 256 KiB. Статичные PNG также доступны на сайте. При обычной отправке WebM вложением Telegram может показать его как видео: для поведения настоящего стикера добавьте файл в набор или используйте бота.

Документация: [Bot API](https://core.telegram.org/bots/api), [видео-стикеры](https://core.telegram.org/stickers/webm-vp9-encoding).
