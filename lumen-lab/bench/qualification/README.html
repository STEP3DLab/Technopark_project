Программа приёмки LM-04B Q/2

Рабочая страница принимает реальные записи регистратора и подтверждения ручного контроля. На ней выполняются 12 проверок: B01–B04, три температурные точки B05a–c и B06–B10. Обновление программного комплекта имеет обозначение B2; геометрия корпуса B1, электроника и готовая прошивка сохраняют собственные обозначения.

Начало работы

  1. Сверьтесь с заданием мастерской и методом сопоставления.
  2. Заполните реквизиты и критерии. Скачайте план до опыта. Номера board и ROM берутся из подключённого регистратора. Для температурного сопоставления необходимы контрольный прибор с документом и обоснованные условия метода.
  3. Приложите JSONL в соответствующие сценарии, CSV контрольного термометра и подтверждения B01–B03. Данные с меткой synthetic не принимаются для физической приёмки.
  4. Выгрузите полный комплект JSON. Он содержит исходные файлы, их SHA-256, текущий план и расчёт. Восстановление заново проверяет хеши файлов и пересчитывает результат. Браузер хранит рабочую запись в IndexedDB этого профиля, но самостоятельная выгрузка обязательна для передачи или архива.
  5. Представьте комплект ответственному специалисту. «Готов к рассмотрению» — предварительный статус, который не заменяет его проверки и подписи.

Страница работает по HTTPS и на localhost. Для локального запуска распакуйте весь архив, выполните python -m http.server 8000 из его корня и откройте http://localhost:8000/bench/qualification/. Собственные данные не отправляются на сервер. Открытие локального HTML двойным щелчком не является поддерживаемым режимом JavaScript-модулей.

Проверка вне браузера

Node.js 22+ без сторонних зависимостей, из папки bench:

node qualification/verify.mjs LM04B-001-evidence.json

Код 0 означает готовность вычисленного комплекта к рассмотрению, 2 — неполноту или несоответствие, 1 — ошибку формата или целостности. Сохранённый в файле assessment не используется как доверенный результат: проверка пересчитывается из исходников. Показания контрольного прибора сопоставляются только с явно указанными seq; интерполяции нет.

Что проверяет программа

  • Совпадение board и ROM с планом, отсутствие незаявленной смены датчика.
  • Число кадров, длительность по ms, непрерывность seq и отсутствие шага более 1,5 с.
  • Статусы обоих каналов для каждого сценария, новый boot после перезапуска.
  • Три стабильных температурных точки, достаточное число и временной охват пар с контрольным прибором.
  • Отклонение и расчётную неопределённость по явному бюджету, правило решения с защитной полосой.
  • Повторное чтение нормализованных данных и наличие подтверждений ручного контроля.

Программа не устанавливает достоверность происхождения файла по одному его содержимому. Логи, снятые до начала записи, ошибки транспорта, не сохранённые программой сбора, и полнота предъявления всех опытов требуют отдельного контроля. SHA-256 обнаруживает изменение байтов относительно предъявленной хеш-суммы; он не является электронной подписью и не доказывает источник измерений.

Состав полного комплекта JSON

Поле Содержание
version LM04B-evidence/2
plan, planSha256 Текущие реквизиты, критерии, допущения и хеш текущего плана
planSnapshots Сохранённые пользователем планы с временем и собственными хешами. Сами по себе не доказывают время фактического опыта
files Исходные байты в UTF-8 или Base64, размер, имя и SHA-256; назначение файла задаётся ключом
manual Отметки B01–B03 и описание фактического результата
evidenceManifest Перечень предъявленных файлов
assessment Результат расчёта, который можно пересчитать независимо
limitations Явные границы вывода

Один файл не более 16 МиБ, сумма исходных файлов не более 64 МиБ. Проверка ручного пункта требует заметку не короче 20 символов и приложенный файл. Содержание фото или PDF автоматически не интерпретируется. Данные хранятся на компьютере пользователя и в выгруженном им комплекте.

Воспроизведение цифровых проверок

node --test checks/*.test.mjs

Сценарии тестов создают только программные примеры в памяти процесса. Они не заполняют рабочую страницу успешными измерениями. Реальный аппарат и регистратор этим тестом не квалифицируются.
