# Минута на открытие — инженерный клуб

Игровой сайт для курса цифровой метрологии Технопарка РГСУ, в духе «Что? Где? Когда?».

**Играть:** https://step3dlab.github.io/Technopark_project/metrology-club/

## Три вечера

| Игра | Темы |
|---|---|
| Охота за формой | Оптическое сканирование, текстура, масштаб, восстановление поверхности |
| Цена микрона | Неопределённость, базы, измерительное усилие, прослеживаемость |
| Замысел инженера | Реверсивный инжиниринг, изготовление, NASA и история техники |

Каждый пакет: 10 обычных вопросов, один чёрный ящик и блиц из трёх вопросов. Всего **36 секторов / 42 отдельных вопроса**. Формулировки авторские; база db.chgk.info использована только как образец жанра. Учебные ситуации не выдаются за реальные исторические события. Ответы содержат критерии зачёта, пояснения и первичные источники.

## Как провести

1. Откройте сайт на компьютере ведущего. Выберите пакет, название команды и формат: до 6 очков либо все 12 секторов.
2. Нажмите «Экран для зала» и перенесите новое окно на проектор. Оба окна должны оставаться в одном браузере. На одном экране игра тоже работает: открывайте ответ только после версии команды.
3. Крутите волчок. Он случайно выбирает только несыгранные конверты.
4. Прочитайте вопрос и запустите 60 секунд. Доступны пауза, досрочный ответ и учебный режим 90 секунд. В блице всегда 3×20 секунд, переход между вопросами по команде ведущего.
5. Капитан отвечает вслух. При желании запишите версию в поле под вопросом. Ответ ведущему и ответ для зала раскрываются отдельно.
6. Засчитайте ответ по критериям. В блице отметьте каждый принятый ответ: очко знатокам доступно только за все три. Ошибочно присуждённое последнее очко можно отменить.
7. Завершённый раунд сохраняется автоматически. В классическом режиме первый, набравший 6 очков, побеждает. В полном режиме при 6:6 — ничья.

«Пакет ведущего» открывает печатную версию выбранной игры со всеми ответами и источниками. Чёрный ящик можно разыграть без физического реквизита.

## Музыка и управление

Оригинальная синтезированная музыка на Web Audio: вращение, обсуждение, музыкальная пауза, сигналы времени и счёта. Звук активируется после нажатия пользователя; можно выключить и настроить громкость. Фонограммы телепередачи не используются. Музыкальная пауза приостанавливает таймер; продолжение отсчёта запускается вручную.

- `Пробел` — старт/пауза обсуждения.
- `R` — вращение волчка.
- `F` — полный экран.

## Технические сведения

Один автономный `index.html`, без сборки, аналитики, CDN и внешних шрифтов/аудиофайлов. Вопросы находятся внутри `<script id="gameData" type="application/json">`. Статический сайт совместим с GitHub Pages. Можно скачать HTML и играть локально; для устойчивой работы двух окон рекомендуется опубликованная HTTPS-версия.

Партии сохраняются отдельно по пакетам в `localStorage` этого браузера. Синхронизация ведущего и проектора — через `BroadcastChannel` с резервным каналом `storage`. Это один ведущий на одном компьютере, не сетевой многопользовательский сервер. После перезагрузки таймер восстановится на паузе. Ответы отсутствуют на видимом экране зала до команды ведущего, но доступны в открытых исходниках.

## Проверки

Проверены синтаксис JavaScript; прохождение всех 36 секторов без повторов; блокировка повторного начисления очка; зачёт блица 3/3; остановка при 6 очках и завершение полного пакета; отмена очка; точность остановки/продолжения таймера; музыкальная пауза; восстановление партии; отсутствие ответов и записанной версии капитана в сообщении для зала до раскрытия. Также проведена браузерная проверка основного экрана, игрового стола и мобильной компоновки.

Неофициальный учебный проект. Не связан с правообладателями телепередачи.
