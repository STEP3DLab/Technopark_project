# Запись с USB на компьютере

Оригинальная Raspberry Pi Pico с прошивкой LM-04B выдаёт сообщения LM04B/1 по USB. Для настольной записи нужен Python 3.9 или новее и PySerial 3.5. Установите зависимость в выбранное окружение Python. Подключите приготовленную плату кабелем с передачей данных. Закройте последовательный монитор, Thonny и вкладки, использующие этот порт.

```sh
python -m pip install pyserial==3.5
python -m serial.tools.list_ports -v
```

Замените порт на показанное системой имя. Запустите из папки desktop. Пример для Windows сохраняет 60 кадров.

```sh
python record.py --port COM4 --out run-001.jsonl --count 60
```

В Linux порт Pico обычно выглядит как /dev/ttyACM0. В macOS смотрите устройство /dev/cu.usbmodem… в выводе list_ports. Пример ограничивает запись десятью минутами.

```sh
python record.py --port /dev/ttyACM0 --out run-002.jsonl --seconds 600
```

Без предела запись продолжается до Ctrl+C или ошибки соединения. Каждая полная принятая строка сразу сбрасывается в файл. Номер кадра и время платы должны возрастать. Если плата перезапустится или изменится её идентификатор, программа закроет предыдущий файл. Существующий файл защищён от перезаписи. По умолчанию программа сообщает об отсутствии новых правильных кадров через 12 секунд. Изменить ожидание можно флагом --idle-timeout.

Откройте полученный файл кнопкой «Открыть файл» на вкладке «Измерения». Для просмотра одного файла в браузере предусмотрено до 43 200 кадров и до 32 МиБ. Для продолжительных опытов сохраняйте несколько файлов с новыми именами. JSONL содержит идентификаторы платы, запуска и датчиков и относительное время на плате. Для архивирования укажите номер опыта, прибор и документ о калибровке в раскрывающемся разделе журнала и выгрузите отчёт JSON вместе с исходной записью.

Быстрая проверка без оборудования в Linux — тест проверяет фактический запуск консольного регистратора, чтение PySerial из псевдотерминала, разрыв и восстановление границ строк, отказ одного канала и файл на диске. Эмулированные данные в тесте заданы заранее.
```sh
python -m unittest discover -s ../checks -p test_recorder.py -v
```
