# Живая инженерная память · v2

Публичный интерактивный атлас СКБ Технопарка РГСУ.

https://step3dlab.github.io/Technopark_project/engineering-memory/

## Реализовано
- 26 объектов, 37 типизированных связей, 8 открытых источников.
- SVG-карта с переходами, паспортами связей, масштабированием и перемещением.
- На мобильном экране ближайшие связи раскрываются вокруг выбранного объекта.
- Поиск по заголовкам, описаниям, вариантам имён, источникам и расхождениям.
- Поиск кратчайшего пути BFS с возможностью исключить редакционные связи.
- Хронология, три досье расхождений и показ из шести шагов.
- Прямые ссылки на карточки, экспорт корпуса и реестра JSON.
- Личные заметки в localStorage с экспортом TXT.
- Предыдущая мастерская сохранена в workshop.html вместе с прежним ключом localStorage.

## Данные и расширение
`data.json` — редактируемый корпус. `data.js` содержит его идентичную копию для работы без fetch, в том числе с локального диска. При изменениях обновлять оба файла.
У каждого узла id, тип, дата, краткое описание, sources и locator. Каждая историческая связь содержит sources. Связи проекта имеют status=project и рисуются пунктиром. Наличие источника не означает экспертную верификацию.
Годы у объектов относятся к выбранной в карточке вехе, а не всегда к году создания организации; у Батанова 1946 — год рождения.
Путь графа не доказывает причинность, личное знакомство или вклад, не описанный источником.

## Источники
Реестр и адреса находятся в data.json. Дата проверки 02.11.2026. Три адреса (СКТБ, ЦНИИ РТК, библиотека МГТУ) сверены по индексируемому тексту при недоступности прямого открытия; ограничения показаны на сайте.

## Границы
Статический рабочий прототип GitHub Pages. Нет сервера, авторизации, фонового сканирования интернета, LLM, OCR и общего редакторского хранилища. Личные записи остаются в браузере. Полный фотоархив и рукопись не опубликованы. Это стартовый корпус, а не полный каталог всех интернет-сведений.

## Запуск и проверки
Открыть index.html или обслуживать каталог статическим сервером. Без сборки и API-ключей.
`node verify.mjs` проверяет целостность корпуса, основания связей, идентичность JSON/JS, поиск и кратчайшие пути.
Браузером проверены переход по SVG-узлу, поиск, цепочка Батанов → ЦНИИ РТК, заметка, показ и мобильная вёрстка 390px.
