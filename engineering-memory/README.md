# Живая инженерная память · v4

Интерактивный атлас СКБ Технопарка РГСУ.

https://step3dlab.github.io/Technopark_project/engineering-memory/

## Что работает
- 35 объектов, 52 типизированные связи, 11 записей открытых источников. Библиотечная копия статьи явно обозначена как повтор той же публикации.
- SVG-карта с переходами, паспортами связей, масштабированием и перемещением. По умолчанию видны ближайшие связи выбранного объекта; весь атлас открывается отдельной кнопкой. На телефоне показываются объект и до семи соседей.
- Каталог с поиском по полному тексту личных материалов, фильтрами типа и периода, сортировкой по названию, году и числу связей.
- Пять инженерных разборов: задача → ограничение → решение → основание → вопрос наставнику. Учебный вывод обозначен как редакционный.
- Поиск кратчайшего пути BFS. По умолчанию только связи со статусом documented; проектные связи и личные упоминания включаются явно.
- Сравнение Мобот-Ч-ХВ и Мобот-Ч-ХВ-2 по шести аспектам: задача, рабочие органы, доставка, кабель, управление, измерения. Фильтр пяти изменений, основания и вопросы для проверки. Полная хронология раскрывается ниже.
- Три досье расхождений, презентационный показ из десяти шагов, прямые ссылки на публичные карточки.
- «Мои материалы»: вставка текста / TXT, обнаружение упоминаний по словарю, проверка пользователем, сохранение материала и выбранных связей в localStorage.
- Экспорт личного архива JSON, предварительная проверка и объединение архивов без перезаписи существующих записей. Совпадающие записи пропускаются, конфликты одного ID отклоняются. Удаление записи с отменой последнего удаления в текущей сессии.
- Экспорт публичного корпуса отдельно от личного архива. Личные записи не включаются в публичный JSON-экспорт.
- Папка встречи: добавление вопросов из карточек, решений, сравнения и досье, собственные вопросы, шесть стартовых вопросов. Запись ответа с автором, URL, страницей или таймкодом, журнал дополнений, статусы и поиск по вопросам/ответам. JSON-копия и импорт с проверкой конфликтов; отдельный HTML-лист для печати и сохранения в PDF средствами браузера.
- Редактирование личных материалов, просмотр истории, восстановление старого текста новой версией. Предыдущие тексты и выбранные упоминания сохраняются. Черновик редактирования сохраняется при переходах между разделами в текущей вкладке, но не после перезагрузки.
- Личная исследовательская заметка с экспортом TXT сохранена в разделе «Досье».
- Старая мастерская сохранена в workshop.html с прежним ключом localStorage.

## Данные
`data.json` — редактируемый публичный корпус. `data.js` содержит идентичную копию для работы без fetch. При изменениях обновлять оба файла.
Исторические узлы и связи имеют sources; locator указывает раздел. Статус documented означает «описано в источнике», а не экспертную верификацию. Проектные связи имеют status=project. Личные упоминания — status=local; никогда не становятся documented автоматически.
`comparison` содержит сопоставление модификаций с основаниями и вопросами. `decisions` содержит редакционные разборы с отдельными вопросами и учебными выводами. Годы у объектов относятся к указанной вехе; у Батанова 1946 — год рождения.
Путь по графу не доказывает причинность, личное знакомство или вклад, не описанный источником.

## Личный архив
`memory-core.js` — чистые функции словарного поиска, проверки URL, схемы и объединения архивов. Поиск учитывает границы слов и приоритет полного названия модели над вложенным коротким. Это не LLM и не семантическое установление исторических связей.
Ключ `engineering-memory-materials-v3` сохранён, новый формат `{format:"engineering-memory-personal",version:2,materials:[...]}`. Архивы версии 1 читаются без потери записей; версия 2 записывается при следующем успешном сохранении. До 100 материалов, 40 000 символов в одном и 1 млн символов текста суммарно, включая историю. Каждый материал содержит id, title, text, year, url, links, createdAt, updatedAt и history. Допускается до 20 предыдущих версий; при достижении лимита новая правка отклоняется без удаления старых. Восстановление создаёт новую версию; одинаковая правка не дублируется. Ссылки разрешены только HTTP/HTTPS без встроенных учётных данных. Недопустимые значения и неизвестные связи отклоняются; пользовательский текст экранируется при выводе.
При ошибке чтения существующий архив не перезаписывается: можно скачать исходную копию. При переполнении хранилища состояние не изменяется. Изменения из другой вкладки обнаруживаются перед записью; устаревшая вкладка не перезаписывает архив. Личные файлы и тексты не отправляются на сервер. Для переноса и сохранности нужно скачивать JSON; очистка данных браузера удалит локальные записи.
Папка встречи хранится отдельно: ключ `engineering-memory-meeting-v1`, формат `{format:"engineering-memory-meeting",version:1,items:[...]}`. До 100 вопросов и 30 записей ответа на вопрос. Статус «Есть запись ответа» требует хотя бы одной записи и не означает исторической верификации. Ответы добавляются в журнал; предыдущие ответы не редактируются. Время записей отображается по Москве. JSON материалов и JSON встречи не взаимозаменяемы.

Ключ заметок `engineering-memory-research-v2` сохранён. Данные старой мастерской остаются в её собственном хранилище, автоматическая миграция не выполняется.

## Запуск и проверка
Открыть index.html или обслуживать каталог статическим сервером. Сборка, зависимости и API-ключи не требуются.
`node verify.mjs` проверяет ссылки, идентичность JSON/JS, поиск, BFS, границы слов, приоритет моделей, архивный формат, объединение, недопустимые URL, лимиты и исключение личных связей из документированных путей.
`node verify-v4.mjs` проверяет миграцию архива, историю/восстановление, лимиты, конфликты, схему папки встречи, ссылки сравнения, экранирование HTML-листа, защиту от записи устаревшей вкладкой и ошибки хранилища.
В браузере v4 проверены сравнение и фильтр изменений, добавление вопроса, два ответа с сохранением после перезагрузки, поиск по раннему ответу, статусы, предварительный импорт, повторы и конфликты, редактирование материала, переходы с черновиком и восстановление версии. Мобильная проверка: фрейм 390px, сравнение, папка и диалог ответа без горизонтального переполнения.
В браузере v3 проверены словарный разбор, снятие лишнего упоминания, сохранение после перезагрузки, поиск личного текста, карточка, границы BFS, объединение архива, каталог и мобильная вёрстка 390px.
