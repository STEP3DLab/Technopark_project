# Люмен LM-04 · Ревизия A

Производственный комплект для пассивного эргономического макета пульта. В макете нет электроники и источников излучения. Интерактивная часть работает в браузере, отдельно от физического пульта.

## Что сделать в мастерской

1. Откройте docs/guide.pdf. В нём чертежи, ориентация печати, расходники, последовательность сборки и лист приёмки. Последнюю страницу с маркировкой можно напечатать отдельно в масштабе 100 %.
2. Подготовьте позиции из docs/bom.csv. Из папки print напечатайте по одной детали 01–04 и четыре экземпляра детали 05. STL заданы в миллиметрах и ориентированы для печати.
3. Выполните сухую примерку до наклейки ленты. Проверьте потайные головки и устойчивость на плоскости, затем соберите корпус, панель, вставку экрана и метки. Отметьте результаты проверки в руководстве.

## Файлы

- lm04-assembly.step — сборка в миллиметрах для FreeCAD и других САПР.
- lm04-assembly.glb — цветная пространственная модель.
- lm04-model.py — параметрический исходник для Python и CadQuery 2.7.0; инструкция запуска находится в начале файла.
- lm04-geometry.json — размеры, объёмы сеток и результаты проверки на взаимное пересечение.
- docs/panel.pdf — размерный чертёж лицевой панели.
- docs/requirements.md — границы демонстрационного проекта и вопросы для согласования с медицинским партнёром.

Сборочный размер 180 × 134 × 77,8 мм. Расчётный зазор по краю вставок — 0,25 мм на сторону. Четыре винта с потайной головкой ST2,9 × 16 DIN 7982. Лента — 0,2 мм.

Проверены геометрия и замкнутость всех пяти STL, а также 66 пар компонентов в цифровой сборке. Испытание физического отпечатка ещё предстоит. Для изменений редактируйте параметрический исходник, повторите цифровые проверки и запишите результаты физической примерки.
