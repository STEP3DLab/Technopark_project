# Версия 0.19.0: исследование и пилот полных сообщений

11 ноября 2026. [Исследование](../app/research.html) · [Кабинет пилота](../app/pilot.html).

## Что изменилось

В приложение добавлены две связанные страницы. Исследовательская страница содержит фактические результаты новой проверки, архивы данных из материалов НТС и направления следующей работы. Кабинет пилота переводит прежнее текстовое задание на 20 сообщений в рабочий процесс регистрации локальных видео и оценок. Он не содержит новых переводов РЖЯ или вымышленных результатов.

Основной словарь из шести слов, текущий распознаватель и исходные движения сохранены. Новый эксперимент хранится отдельно и не включает автоматического перевода предложений. Старые 12 контрольных видео в интерфейсе явно обозначены как историческая проверка 28 октября.

## Выполненный эксперимент

Из официального Slovo извлечены 192 выбранных ролика (142 091 617 байт), с проверкой размеров, CRC и SHA-256. MediaPipe Holistic 0.10.21 обработал все 192; ошибок загрузки и извлечения нет. Выборка: train 76 / 7 исполнителей, validation 43 / 1 исполнитель, test 73 / 46 исполнителей. Во всех парах частей нулевое пересечение исполнителей. Исторические исполнители исключены. Неизвестные метки validation/test не пересекаются.

| Метод | Известные: верно | Ошибочно принято | Отказ | Неизвестные: принято | Отказ |
|---|---:|---:|---:|---:|---:|
| 21 образец, пороги 0,42 / 0,055 | 2 | 0 | 11 | 2 | 58 |
| 76 образцов, пороги 0,42 / 0,055 | 7 | 0 | 6 | 4 | 56 |
| 76 образцов, пороги 0,34 / 0,08 | 4 | 0 | 9 | 0 | 60 |

Знаменатели: 13 известных видео пяти классов; 60 неизвестных видео 30 классов. «Друг» в новом положительном тесте не представлен. Top-1 до порогов: 9/13 у всех трёх вариантов. Ошибочные принятия определяются относительно метки Slovo; без лингвистической экспертизы нельзя считать каждое такое событие доказанной ошибкой смысла.

Расширение библиотеки увеличило число принятых известных слов, но и принятие неизвестных. Настройка порогов уменьшила последнее до нуля в этой серии и сохранила 4 верных ответа. Один настроечный исполнитель и малый положительный тест не подтверждают устойчивость для общей аудитории. Проверка не измеряет свободную речь, понятность аватара или скорость камеры на телефоне.

Порог зафиксирован в `candidate.json` до теста. После этого входы и расчётные модули не изменялись; хеши сверены перед итоговой оценкой. Первая попытка запуска была остановлена до ранжирования из-за различия регистра русских названий (`да` / `Да`); проверка отображаемого текста уточнена до фиксации кандидата, без изменения классов, последовательностей или состава данных.

## Как воспроизвести

Из `hearing-equality`:

```sh
npm test
npm run verify
npm run evaluate
npm run research:evaluate
```

Новый отчёт уже включён. Последняя команда сверяет все замороженные входы, повторяет тестовые предсказания и требует точного совпадения существующего отчёта. Повторная калибровка поверх `candidate.json` запрещена намеренно: для нового исследования нужен отдельный протокол и тест.

Для независимого воспроизведения подготовки в отдельной копии каталога:

1. `prepare_research_v019.py` читает официальный `annotations.csv` и строит детерминированный отбор. SHA-256 исходных аннотаций: `8e5595d6431974dd7e93ad21f41dec0401c0e8686bcafbdc093c5edebbdfba49`.
2. `fetch_research_v019.py` извлекает только выбранные файлы из ZIP через HTTP Range, проверяет CRC и SHA-256.
3. `extract_research_v019.py` обрабатывает видео существующим `extract_motion.py`. Проверенная среда: Python 3.12, MediaPipe 0.10.21, opencv-contrib-python 4.11.0.86, numpy 1.26.4.
4. `build_research_features_v019.mjs` сохраняет компактные признаки; исходные 21 последовательность не пересчитываются для сравнения вариантов.
5. В новом каталоге без зафиксированного кандидата `research-evaluate-v019.mjs --calibrate` использует только validation и фиксирует входы; затем `--evaluate` открывает тестовые ответы.

Состав, аргументы и ограничения подробно приведены в скриптах и [плане](../research/v019/PROTOCOL.md). Признаки и оригинальные видео подчиняются [условиям Slovo](../THIRD_PARTY.md).

## Кабинет 20 сообщений

- Локальные материалы с контрольной суммой, условным кодом исполнителя и разделом train / validation / test.
- История языковых проверок, исходный ответ до оценки, отдельные оценки смысла, отрицания и вопроса.
- Показ без русской подписи для проверки понимания; исполнитель и зритель должны различаться.
- Отказы, пропуски и повторные попытки сохраняются. Исправленный текст не заменяет первоначальный ответ.
- JSON для продолжения, CSV для анализа. Видео не входят в выгрузку; добровольное сохранение относится только к журналу.

Подробности: [правила кабинета](PILOT_WORKBENCH_V019.md). Система учёта не заменяет реальную работу переводчика, квалификацию проверяющих или единый организационный реестр людей.
