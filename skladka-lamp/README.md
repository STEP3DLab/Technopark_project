# СКЛАДКА / настольный светильник — дизайн-концепция

Параметрический настольный светильник с плиссированным абажуром и встроенным русскоязычным 3D-конфигуратором. Концепция предметного дизайна, **не рабочая конструкторская документация и не готовое электротехническое изделие**.

## Просмотр

Откройте `index.html` в современном браузере, поддерживающем WebGL 2.0. Приложение полностью автономно: нет зависимостей от CDN, сборщика, аккаунтов, ключей API или сторонних JS-библиотек. Единственная факультативная внешняя загрузка — шрифт Manrope (при отсутствии интернета применяется системный).

Для запуска через локальный сервер: `python -m http.server 8000` из папки проекта, затем `http://localhost:8000/`.

## Управление

- Перетаскивание мышью / одним пальцем: вращение вокруг светильника.
- Колёсико / жест двумя пальцами: приближение и отдаление.
- Три согласованные отделки: молочная, терракота, графит.
- Ползунки меняют настоящую 3D-геометрию (высота абажура 120–180 мм, число складок 16–36).
- Свет: включение/выключение визуального тёплого свечения (2700 K — концептуальный ориентир).
- «Разнести детали»: анимация 5 групп компонентов с выносками.
- ↺: возвращение к презентационному ракурсу с сохранением выбранной отделки и параметров.
- GLB: сформированный в браузере бинарный glTF 2.0 (реальная модель собранного светильника, метры, материалы, названия деталей, без фотографий и элементов интерфейса).
- PNG: снимок текущего ракурса 3D-сцены без интерфейса.

## Геометрические решения

Номинальная высота 320 мм; диаметр абажура около 200 мм, основания 124 мм. Высота корпуса 150 мм, 28 складок в начальной конфигурации. Плиссированная стенка включает наружные и внутренние поверхности, толщину ~1,55 мм, торцевые стенки и острые физические грани. Открывающийся снизу рассеиватель, компактный LED-модуль, стержень Ø9 мм, втулки и утяжелённая опора представлены отдельными мешами. Реализация материалов — предварительная: корпус как матовый полупрозрачный полимер или формованный композит, основание как окрашенный металл.

### Инженерные вопросы перед изготовлением

1. Цифровая модель демонстрационная; измеренные характеристики устойчивости и прочности не подтверждены расчётом или испытаниями. Для прототипа предусмотреть груз в основании, проверку центра тяжести и кабельный ввод.
2. Подтвердить технологию формирования и минимальную толщину плиссировки (литьё, термоформование либо 3D-печать), доступ для сборки и чистки.
3. Выполнить тепловой расчёт LED-модуля и металлического радиатора; рассчитать электробезопасность, драйвер, кабель, выключатель, сервисный доступ и требования применимого техрегулирования.
4. Для производства нужны КД/STEP, допуски, спецификация компонентов, сборочные чертежи, прототип и тесты. Файл GLB предназначен для дизайна и презентации, не заменяет STEP.

## Код

- `index.html` — русскоязычный интерфейс, семантика и доступные элементы управления.
- `style.css` — responsive-композиция предметной презентации.
- `app.js` — собственный WebGL2-рендерер, геометрия, управление камерой, анимация и экспорт glTF/PNG.
