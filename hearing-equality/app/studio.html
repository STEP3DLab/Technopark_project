Равенство по слуху

От записи — к аватару

Этот демонстратор помогает исследовать воспроизведение жестов и удобство взаимодействия с цифровым персонажем.

Новое в v0.3

Последовательный демопоказ, три цвета одежды, просмотр по кадрам и ссылка с настройками студии.

01

Выбираем слово

Текст сопоставляется с одной из шести доступных записей демонстрационного словаря.

02

Воссоздаём движение

Аватар использует измеренные координаты тела, лица и кистей. Его можно сравнить с исходным видео.

03

Проверяем понимание

Следующий этап — оценка переводчиком РЖЯ и участниками сообщества глухих.

Границы этой версии

Это технический демонстратор шести слов. Свободного перевода предложений и подтверждённого понимания РЖЯ в этой версии нет.

Аватар Canvas 2D следует координатам, автоматически извлечённым MediaPipe. При потере кисти детектором её пальцы временно не показываются. Стилизованная внешность не является частью исходной записи.

Для реальных оповещений и ответственной коммуникации нужны проверенные переводы.

Происхождение данных

Движения из Slovo

Alexander Kapitanov, Karina Kvanchiani, Alexander Nagaev, Elizaveta Petrova. Slovo: Russian Sign Language Dataset.

Шесть исходных видеоклипов сохранены без изменения. Координаты автоматически извлечены с помощью MediaPipe; изображение аватара и переходы построены программно. Данные и их адаптация предоставляются по специальной публичной лицензии Slovo, как есть, без гарантии качества перевода. Авторы Slovo не заявлены проверяющими этого проекта.
