# Переход на версию 2.0

В репозитории подготовлена рабочая версия 2.0 панели управления проектами Технопарка РГСУ.

## Рабочая ссылка

https://step3dlab.github.io/Technopark_project/index-v2.html

## Что включает версия 2.0

1. Экспертная матрица приоритетов проектов.
2. Контроль качества данных реестра.
3. Автоматическая повестка НТС.
4. Раздел проблемных проектов.
5. Грантовый календарь.
6. Отчет для проректора.
7. Карточка проекта по клику.
8. Готовность комплекта документов.
9. Режим презентации.

## Как сделать версию 2.0 основной

Вариант 1 - вручную в `index.html` перед `</body>` добавить:

```html
<script src="improvements.js"></script>
```

Вариант 2 - после проверки заменить содержимое `index.html` логикой из `index-v2.html`, чтобы основная ссылка сразу открывала улучшенную версию.

## Почему пока используется index-v2.html

Текущий `index.html` большой и содержит интеграцию с Google Таблицей и Apps Script. При работе через GitHub API безопасное точечное обновление требует актуальный blob SHA файла. Инструмент не отдал его в usable-виде, поэтому прямое изменение основной страницы не выполнялось, чтобы не сломать рабочую интеграцию.
