# Живая инженерная память
Интерактивный прототип банка инженерных знаний СКБ Технопарка РГСУ.

## Открыть
https://step3dlab.github.io/Technopark_project/engineering-memory/

## Возможности
- Банк знаний с поиском по пилоту и локальным записям.
- Профиль А. Ф. Батанова и создание карточек специалистов.
- Кейс «Чернобыль и роботы»: обзор, связи, источники, учебные задачи.
- Архив: текст, описание, авторство, внешняя ссылка, импорт TXT до 100 КБ.
- Мастерская: выделение задачи, ограничения, вариантов, решения и результата по явным меткам.
- Сохранение черновых карточек и экспорт Markdown.
- Экспорт/восстановление локальных данных JSON.
- Адаптивная вёрстка без внешних зависимостей.

## Границы прототипа
Данные сохраняются только в localStorage текущего браузера и не синхронизируются.
При очистке данных браузера записи теряются — используйте экспорт.
AI/LLM, OCR, распознавание речи, общая база и авторизация не подключены.
Разбор текста — прозрачный алгоритм извлечения строк, не проверка исторической достоверности.
Подлинные материалы Батанова не загружены. Основная карточка основана на описании инициатора.
Учебные примеры не являются цитатами или свидетельствами Батанова.
Импорт сохраняет текст, а не исходные бинарные документы.
Права доступа и согласование публикации в промышленной версии необходимо реализовать на сервере.

## Запуск
Открыть index.html либо обслуживать каталог любым статическим HTTP-сервером.
Нет сборки и ключей API. Совместим с GitHub Pages.

## Проверка
Проверены синтаксис JavaScript, генерация 7 экранов и 4 вкладок кейса,
извлечение полей, сохранение и защита от дублирования карточек,
сброс устаревшего результата, поиск, экранирование и проверка ссылок.
Браузерная визуальная проверка в этой среде не выполнялась.
