# Северный маршрут

[Открыть диспетчерскую](https://step3dlab.github.io/Technopark_project/karelia-uav/)

MVP Технопарка РГСУ для пилота беспилотного мониторинга дорог Карелии. Приложение работает как статический сайт. Для локального запуска выполните `python3 -m http.server 8000` в этом каталоге и откройте http://localhost:8000/.

## Демонстрация за две минуты

1. На учебном маршруте Кестеньга — Зашеек выберите 44-й километр.
2. Сдвиньте границу между двумя кадрами, включите контуры изменений и осмотрите участок у трубы.
3. Создайте заявку, укажите задание и откройте раздел «Заявки».
4. Скачайте файл для бригады или откройте его версию для печати. Координаты, описание и обе фотографии входят в файл. После выезда отметьте выполнение.
5. В «Практикуме» есть упражнение для оператора. Для проверки на своих данных нажмите «Загрузить облёт». Нужны два снимка с сопоставимым ракурсом и координаты участка. В форме доступны оба учебных кадра.

## Обработка и хранение

Анализ выполняется в браузере. Снимки уменьшаются для расчёта, затем алгоритм компенсирует общий цветовой сдвиг и небольшой сдвиг камеры, сравнивает локальные участки и группирует их с помощью k-means. Соседние изменившиеся области объединяются в рамки. Классификацию события и решение о выезде подтверждает диспетчер. Сильная смена ракурса, освещения или сезона может повлиять на результат.

Учебные координаты, схема дороги, сгенерированные изображения и уровень воды служат для демонстрации. Подключение полётного контроллера, телеметрии и физического датчика требует интеграции на пилотном участке. Загруженные кадры, заявки и статусы хранятся в IndexedDB текущего браузера. Бригаде передают экспортированное задание вручную. Очистка данных сайта удаляет местный журнал.
